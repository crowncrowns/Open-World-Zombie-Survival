# Terrain Roads — применение

Инструмент: Tools > Terrain Roads > Create from selected Spline (separate object).
Выделите Spline или Spline (1), выполните команду, назначьте Vidnoe_Terrain в новом объекте.
У нового объекта собственный MeshRenderer; исходный SplineContainer остаётся маршрутом.
В Scene редактируйте узлы штатным инструментом Splines, ширину — голубым handle на новом объекте.
При нескольких сплайнах выберите splineIndex в Inspector. Начальные значения: ширина 6 м,
шаг 1 м, сглаживание 8 м, offset 0.035 м. Rebuild обновляет вручную;
autoRefresh реагирует на правки узлов, Undo, Terrain и параметры в Editor каждые 0.75 сек.

Сначала отключите autoRefresh при массовых операциях. Ошибочная геометрия скрывает старый меш,
чтобы не показывать устаревший результат. Для крутых поворотов уменьшите ширину либо увеличьте
радиус. Шаг уменьшайте для более точного обнаружения бугров. Оранжевые сферы показывают
секции, где расхождение Terrain и дорожного профиля больше earthworkTolerance.
Плавная дорога физически не может одновременно повторять каждую кочку: здесь нужна ручная
подготовка копии Terrain. Автоматического изменения высот и кнопки Conform Terrain нет.
Terrain holes и выход за пределы назначенного Terrain запрещены. Несколько Terrain не поддержаны.

Материал копируется с исходного MeshRenderer; назначьте URP/Lit с повторяющейся текстурой
асфальта (Wrap Mode Repeat). V = длина / textureRepeat, U = ширина 0..1.
Тестовый материал серый, без текстуры. Road Collider по умолчанию выключен. Включайте только
если игрок должен идти по сглаженному мешу; Terrain collider остаётся под ним и может
мешать при пересечении профилей — такие секции надо исправить. Не добавляйте collider
на исходный Extrude одновременно с новой дорогой.

До проверки новой полосы сохраняйте исходную дорогу. Чтобы сравнить без Z-fighting,
временно выключите старый MeshRenderer; если SplineExtrude продолжает писать в него,
также выключите этот компонент. Не удаляйте SplineContainer: он нужен новой дороге.
Не применяйте генератор на тот же объект, где SplineExtrude, иначе они делят MeshFilter.
На закрытых маршрутах шов имеет общие позиции и согласованные normals; дробное число
повторов текстуры может дать видимый UV-шов. Развязки, перекрёстки и мосты не генерируются.
Диагностика пересечений работает в XZ, мосты друг над другом отклоняются.
Перекрытия полос диагностируются в XZ методом разделяющих осей; касания в пределах 1 мм нужно проверять визуально.
Максимум 10000 секций; проверка пересечений квадратичная, длинные маршруты делите.

Tools > Terrain Roads > Create isolated demonstration создаёт отдельную additive-сцену
с собственным синтетическим Terrain и двумя маршрутами. Повторный запуск создаёт новые
файлы с уникальными именами. Основная SampleScene не изменяется.
Меш восстанавливается при загрузке сцены и при запуске игры. Для статического экспорта
сначала сохраните меш отдельным asset средствами Editor (встроенной кнопки bake нет).

## Безопасный перенос

Скопируйте ТОЛЬКО новую папку Assets/TerrainRoads вместе с .meta в исходный проект,
предварительно проверив отсутствие одноимённой папки. Не копируйте SampleScene,
ProjectSettings, Packages целиком или унаследованные изменения worktree.
В исходном проекте через Package Manager проверьте Unity Splines 2.9.1 (не понижайте
более новую совместимую версию). Затем дождитесь компиляции и создайте новую дорогу
из существующего Spline. Сначала сохраните сцену под новым именем и работайте с её копией.
RoadPackageSetup — служебный установщик пакета для изолированной проверки, запускать
в исходном проекте не требуется. Не переносите RoadWorkflowBackup и Library.
Никаких commit/push, reset или перезаписи чужих незакоммиченных файлов не выполнялось.
