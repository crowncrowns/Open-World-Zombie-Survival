# Advanced Grass Painter

Редактируемая процедурная трава для Unity **6000.6.3f1**, URP **17.6.0**. Отдельная реализация HDRP Lit Shader Graph проверена с HDRP **17.6.0**. Все исходники, пресеты, материалы, демо и результаты находятся в этой папке. Платные ассеты не используются.

## Быстрый старт

1. Дождитесь импорта. Откройте **Tools → Environment → Advanced Grass Painter**.
2. Нажмите **Новый независимый слой** либо выберите существующий GrassDataStorage и нажмите **Открыть кисть для этого слоя** в Inspector.
3. На вкладке **Presets** выберите один из шести ассетов в `Presets`, затем **Загрузить пресет**.
4. В **Collision Avoidance** назначьте слои земли в **Слои поверхностей**. Слои стен, камней, заборов и остальных препятствий включите в **Слои препятствий**. Рекомендуется отдельный слой земли: маска поверхности задаёт, что художник разрешает считать землёй; крыша на разрешённом слое с допустимым уклоном тоже будет поверхностью.
5. Включите **Кисть в Scene View**. ЛКМ рисует, удержание с протягиванием продолжает мазок; Shift стирает, Alt оставляет навигацию редактора. Ctrl+Z/Ctrl+Y работают через Unity Undo. Кисть недоступна в Play и Prefab Stage.
6. Сохраните сцену обычным Ctrl+S. Пучки и seed сериализуются в компоненте; временные меши восстанавливаются при открытии сцены. Отдельно сохранять каждый чанк не нужно.

Демо: `Demo/AdvancedGrassPainter_Demo.unity`. В нём есть земля, тестовое здание с цоколем, три камня, забор и навес. Один камень специально не имеет Collider. Это техническое демо с простыми окружающими формами, а не готовая художественная локация. `Demo_URP.asset` используется только изолированным сборщиком проверки: пакет не меняет пайплайн основного проекта.

## Режимы и слои

| Режим | Действие |
|---|---|
| Paint | Добавляет пучки с шумовой маской и минимальным пространственным расстоянием |
| Erase | Удаляет пучки в круговой области; подходит для вытоптанных дорожек |
| Smooth | Прореживает скученные пучки и заполняет пробелы более слабой шумовой маской |
| Scatter | Рисует редкую растительность с мягким краем |
| Fill | Одним щелчком заполняет круг кисти; отдельная кнопка заполняет горизонтальную проекцию Bounds выделенных Renderer |
| Replace | Заменяет только выбранный исходный вид на текущий, повторно проверяя изменённую геометрию |
| CollisionCleanup | Удаляет недопустимые пучки в области кисти |

Каждый GrassDataStorage — независимый слой: свой материал, данные, история, качество и дальность. Выключение компонента скрывает слой и освобождает его временные меши. Координаты растений **мировые**: Transform служебного объекта не перемещает поле. Между независимыми слоями нет общего ограничения Poisson — их можно намеренно смешивать.

**Fill по Bounds** использует Renderer выделения; границы по X/Z обрезаются точно, вертикальная поверхность ищется в пределах `Поиск земли ±`. Для очень высокой выбранной геометрии увеличьте этот предел либо заполняйте кистью по земле. Для больших операций доступен отменяемый индикатор прогресса; отменённый Paint/Fill/Scatter не оставляет добавленные растения.

`Активность роста` меняет локальную маску новых мазков: 0 запрещает новый рост, 1 даёт обычный, 2 усиливает его. Удаление уже существующей травы выполняется Erase. Зоны слабого/активного роста авторятся мазками с разными настройками; отдельного runtime-симулятора роста нет.

## Геометрия и воспроизводимость

Каждый пучок содержит 7–11 отдельных изогнутых травинок. Они имеют сужающийся силуэт, шесть сегментов вблизи, небольшой продольный изгиб и складку поперёк листа. Поворот, наклон, высота, ширина, оттенок и направления изгиба вычисляются из сохранённого seed. Urban добавляет широкие листья сорняков. Это процедурная геометрия с вариациями, а не фотосканирование или доказанное AAA-качество.

Шесть пресетов: Short, Wild, Dry, Overgrown, Mixed, NeglectedUrban. Mixed выбирает виды внутри пучков; сухие пятна распределяются низкочастотной маской. Short/Overgrown дополнительно масштабируют высоту относительно базовой настройки. Для недопустимых сочетаний очень маленькой высоты и большой ширины ширина ограничивается половиной высоты; резерв ветра — 30% высоты. Это сохраняет геометрию над локальной касательной к земле.

Распределение использует последовательное случайное размещение с отбраковкой соседей (Poisson disk), пространственный hash, Perlin и три октавы fractal noise. Глобальный seed, seed кисти, сохранённый номер мазка и seed координат чанка участвуют в генерации. UnityEngine.Random не используется и его глобальное состояние не меняется.

Для воспроизведения нужны одинаковые сцена/поверхности/препятствия, настройки, размер чанка и последовательность мазков. `Lock Seed` сохраняет seed каждого мазка. **Regenerate with New Seed** доступна при снятой блокировке; новый seed сохраняется в истории. Обычная перегенерация применяет текущие параметры к истории, сохраняя радиусы/Bounds мазков. После Erase/Replace/Smooth/Cleanup история сбрасывается, чтобы не воскресить удалённую траву: повторная генерация меняет оставшиеся пучки в их точках и сохраняет вид; для вида используйте Replace.

Пресеты — ScriptableObject. JSON экспорт/импорт переносит настройки, а не содержимое слоя. Некорректные числовые диапазоны при импорте ограничиваются допустимыми значениями.

## Обход препятствий

Кэш создаётся в закрытой **Editor Preview Scene с отдельной PhysicsScene**. Исходные объекты, коллайдеры и параметры импортёров не меняются. Используются копии физических Collider и MeshCollider по видимой геометрии Renderer, включая colliderless Mesh и текущую позу SkinnedMeshRenderer. Mesh proxy не становится GameObject основной сцены и не сохраняется в неё.

Проверяются:

- проекция корня вниз и допустимый уклон;
- перекрытия над корнем в заданной высоте;
- положение внутри замкнутой меш-оболочки;
- каждый сегмент каждой итоговой травинки, включая её ширину, складку, погрешность аппроксимации кривой, зазор и максимальное отклонение ветром;
- остальные грани того же меша, который служит землёй: стену объединённого меша нельзя обойти исключением всего ground collider;
- ближайшие ячейки Terrain с консервативным учётом обоих вариантов диагонали;
- форма ближайших препятствий для мягкого снижения вероятности роста.

`GrassObstacle` на объекте/родителе позволяет исключить геометрию, добавить индивидуальный зазор или выбрать физические Collider вместо видимого меша. Триггеры не считаются препятствиями. Если отключаете слой/объект в фильтрах, вы явно разрешаете его игнорировать.

При сложном shear Transform либо недоступной геометрии используется консервативный Bounds proxy; такой proxy не допускается как поверхность рисования. Он может оставить более широкую пустоту. Если supporting mesh не удаётся прочитать через Editor MeshUtility, размещение на нём блокируется. Маски alpha-текстур не вырезают дырки в collision mesh.

**Recalculate Collisions** принудительно перестраивает кэш и очищает весь слой. **Очистка после перемещения** при открытом окне сравнивает объекты раз в секунду и проверяет только старые/новые изменённые Bounds с запасом. Перемещение, удаление, изменение формы/слоя, переимпорт меша и изменения костей учитываются. Очищенные места заполняются заново кистью. В Play кэш и очистка не работают: перемещающиеся игровые препятствия требуют отдельной runtime-интеграции.

Зелёные точки предпросмотра обозначают допустимые пробы, красные — блокированные, жёлтые — спад плотности. Они обновляются с интервалом 0,2 с; это подсказки, окончательная проверка выполняется при генерации. В Debug их можно скрыть.

Абсолютная гарантия для произвольных будущих ассетов не установлена: действуют точность PhysX, контактный допуск локальной поверхности 15 мм и консервативные оболочки. В приложенной тестовой матрице пересечений не найдено, в том числе независимой проверкой по исходным Collider. Изменение препятствий после проверки без повторной очистки, неверные маски и игнорируемые объекты снимают эту проверку.

## Материалы и ветер

URP: `Shaders/GrassURP.shader`, материал `Materials/Grass_URP.mat`. Есть основной свет с тенями, дополнительные источники Forward, ambient probe, затенение основания, просвечивание, двухстороннее отображение, fog, ShadowCaster, DepthOnly и DepthNormals. Положение с ветром общее у цветового/теневого/depth проходов. Не используется прозрачное смешивание или плоская карточка вместо геометрии.

Градиент и вариация цвета находятся в вершинах. `_BaseMap` — необязательная текстура отдельного листа с alpha clipping; по умолчанию белая. Для своей 2K/4K текстуры назначьте её в материал и установите соответствующий Max Size в Texture Importer. Пакет не создаёт искусственную 4K-карту там, где достаточно геометрии и vertex color.

HDRP: в HDRP-проекте нажмите **Tools → Environment → Install Advanced Grass HDRP Shader**, либо кнопку Rendering & Optimization. Установщик импортирует реальный HDRP Lit Shader Graph из `Shaders/HDRP~`, привязывает общий HLSL по GUID и создаёт `Materials/Grass_HDRP.mat`. Исходник хранится в игнорируемой Unity папке, чтобы URP-проект не импортировал отсутствующий HDRP target. Пайплайн и Packages установщик не меняет. HDRP использует свои штатные Lit light/shadow/depth passes, двусторонние нормали, alpha texture, AO и ту же ограниченную GPU-деформацию.

HDRP-проверка выполнялась в отдельном проекте с установленными URP и HDRP 17.6.0; чистый проект только с HDRP не проверялся. TAA/motion vectors, baked GI, SSAO и все комбинации дополнительных render features не входят в подтверждённую матрицу.

`GrassWindController` один на слой. Сила, направление, скорость, порывы, турбулентность, жёсткость и пространственная частота передаются через MaterialPropertyBlock. Сдвиг пропорционален квадрату высоты внутри травинки, поэтому основание неподвижно. Суммарная амплитуда не превышает сохранённый резерв. Для фиксированной фазы выключите `animate` и задайте `phaseTime`; это также позволяет воспроизводить кадры. Изменение резерва требует перегенерации с новой проверкой коллизий.

## Рендеринг и статистика

Используется современный `Graphics.RenderMesh` с уникальными объединёнными мешами чанков, а не GPU instancing одинаковой модели. На видимый чанк подаётся один меш; GameObject на отдельную травинку, пучок или чанк нет. Такой способ сохраняет разные силуэты у растений и существенно сокращает подачи.

- X/Z-чанки по 8 м по умолчанию; неизменённые чанки сохраняют прежние Mesh при редактировании соседних.
- CPU frustum/distance culling перед подачей; запас bounds покрывает ветер.
- LOD0: 6 сегментов, все пучки/листья. LOD1: 3 сегмента и стабильное прореживание. LOD2: 2 сегмента и ещё меньшая вложенная выборка.
- Low/Medium/High/Ultra меняют дальность и пороги LOD. Около камеры всегда LOD0.
- Нет покадрового построения мешей и собственных управляемых аллокаций в штатном camera callback. Перестроение и авторинг выделяют память по изменённым данным.

Debug показывает пучки, травинки, чанки, подачи последней камеры, оценку памяти данных/мешей, время последней генерации и накопленные за текущий процесс отказы из-за препятствий. **Подачи не равны полным Draw Calls**: shadow/depth passes и внутреннее поведение пайплайна добавляют работу. Оценка памяти не включает весь managed overhead, копии драйвера и память PhysX.

В демо подтверждены 2 713 пучков / 29 499 травинок / 16 чанков; около 64,3 МиБ оценочных данных и трёх LOD-мешей. Это не доказательство бюджета большого открытого мира. FPS, GPU timings, streaming, occlusion culling, сборка standalone и миллионные массивы не измерялись. Для большого мира нужны измерения на целевом железе, управление загрузкой слоёв и их плотностью.

## Исходники и повторные проверки

Runtime: GrassPreset/Settings, GrassDataStorage, GrassRandomizationSystem/DensityMask, GrassMeshGenerator, GrassWindController, GrassRenderingSystem/ChunkManager, GrassObstacle. Editor: GrassPainterWindow управляет Scene View кистью; GrassGenerationSystem — операции и Undo; GrassCollisionManager/SupportGeometry — физический кэш и проверка поверхности; GrassHDRPInstaller — импорт отдельного шейдера. Runtime и Editor разделены asmdef.

`Verification` содержит JSON-отчёты и реальные кадры Unity. Воспроизводимые проверки: `GrassVerification.BuildAndCheck`, `GrassVerification.ReloadCheck`, `GrassPlayVerification.Run`, `GrassSceneViewVerification.Run`. Они защищены проверкой пути `work/AdvancedGrassPainter` и **отказываются запускаться в основном checkout**. Сборщик демо меняет сцену и pipeline только изолированной копии. Runtime-проверок на временных MonoBehaviour в продукте нет.

Проверено: сцена со зданием/камнями/забором/навесом, colliderless препятствие и поверхность, одинаковый/новый seed, сохранение нового seed, изменение настроек при перегенерации, точный Bounds Fill, Undo/Redo, независимые Physics capsule-проверки, перемещённое препятствие, Mesh с землёй и стеной, уклон 70° при лимите 55°, область 46 м на неровном Terrain 128×128 м, повторное открытие сцены, холодный запуск Unity, Play lifecycle/culling/quality, GPU wind по пикселям, Scene View щелчок/drag/Shift/Undo через события редактора, native HDRP rendering.

Scene View проверен **скриптовыми событиями Unity Editor**, не физической мышью ОС пользователя. Основной CharacterTest, player/world-save, NPC/AI/предметы и настройки игры не изменялись и не запускались. Сохранение травы относится к Unity-сцене, а не к F5/F9 игре.

В изолированном Play-проекте Unity SearchDatabase при старте выдал `ArgumentOutOfRangeException` внутри `UnityEditor.Search.SearchDatabase.EnumerateAll`. Проверки инструмента продолжились и прошли; исключение редактора не замаскировано и не считается отсутствующим. Полные журналы текущей рабочей проверки — `work/AdvancedGrassPainter/*.log` вне распространяемого пакета; они не входят в пользовательскую сцену.
