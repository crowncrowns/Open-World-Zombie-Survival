# Dirty Hazy Glass 01
M_Glass_DirtyHazy.mat — отдельная копия Assets/Maps/Interior/Materials/M_Glass_Clear.mat с тем же URP Lit, прозрачным режимом, blend/depth/cull/queue параметрами. Исходник не изменён (SHA256 проверен).
Добавлены неоднородный пыльный налёт, слабые разводы/мелкая фактура. BaseColor RGBA: RGBсеро-зелёный налёт, alpha.23–.65; материал BaseColor white/alpha1. Smoothness берётся из MetallicSmoothness alpha=1−roughness; Roughness.52–.86. Metallic0. Нормали очень слабые BumpScale.15.
10карт1024²: BaseColor RGBA, Opacity, DirtMask, Roughness, Normal_OpenGL, Metallic, MetallicSmoothness, AO, ORM, Height16. Подключены BaseColor/Normal/MetallicSmoothness; прочие для дополнительной настройки. RepeatUV, данныеlinear, цветsRGB, исходник1254². Высота/roughness/opacity приближённо оценены из сгенерированной маски, не физическое измерение. Из-за смешивания по прозрачности эффект зависит от освещения и фона.
Важно: стандартный URP Lit передаёт грязь и визуальную мутность через налёт/прозрачность/шероховатость, но НЕ размывает предметы позади стекла. Настоящее матовое стекло с размытием требует отдельного шейдера. Никакие сцены, префабы и назначения материалов автоматически не менялись.
Для меньшей непрозрачности снизьте Alpha у BaseColor материала (он умножает alpha текстуры). Для масштаба разводов используйте Tiling. Исходный материал односторонний (Cull Back); это сохранено.
