# Aggregate Panel 3×3
Текущий проект: S:/Games/Unity Projects/Open World Zombie Survival.
Папка Assets/Maps/Buildings/Textures/AggregatePanel3x3_01. Материал M_AggregatePanel3x3_URP.mat, URPLit.
Одна лицевая панель3×3м: UV0–1, Tiling1×1, Offset0. Светлый шов по периметру, соседние панели образуют общую сетку стыков. Материал использует обычныеUV, не мировые координаты; на торцы предпочтительно отдельное назначение. Если UV повёрнуты/выходят за0–1, сетка швов сместится.
8карт2048²: ACP01_BaseColor, Normal_OpenGL, Height16, AO, Roughness, Metallic, MetallicSmoothness, ORM. Repeat/mipmaps/Trilinear/aniso8; цветsRGB, остальныеlinear, NormalMap. Metallic0, Roughness.93; Normal1, Parallax.003. Рельеф слабый, не меняет геометрию/коллайдеры.
Цвет сгенерирован built-in image_gen по референсу. Исходник1254² пересчитан2048² с обрезкой к середине краевых швов. Height/Normal/AO приближённо из локальной фактуры, цвет камней не является точной высотой; не скан.
Материал/метаданные сохранены, GUID URPLit сверён с установленнымURP, ссылки на локальные карты проверены. Открытый Editor с Pipeline для этого проекта не найден: компиляция и визуальная проверка в Unity не подтверждены. При открытии проекта Unity импортирует готовыефайлы; автоматическая сборка дополнительным скриптом не требуется. Сцены/исходные материалы/Packages не менялись.
