# Кора городских деревьев — 4 материала
Папка Assets/Maps/Buildings/Textures. UrbanBark_Birch_01 (берёза), UrbanBark_Poplar_01 (тополь), UrbanBark_Linden_01 (липа), UrbanBark_Maple_01 (клён).
В каждой папке готовый M_UrbanBark_<вид>_01_URP.mat и8карт2048²: Bark_BaseColor (sRGB), Normal_OpenGL (NormalMap,+Y), Height16 (16bit), AO, Roughness, Metallic (0), MetallicSmoothness(RGB0/alpha1−roughness), ORM(R=AO,G=roughness,B=metallic).
Материалы для СТВОЛОВ и крупных ветвей, без листьев и геометрии деревьев. URPLit, матовые, RepeatUV, mipmaps/Trilinear/aniso8. Начальный повтор примерно1×1м; UV V направить вверх вдоль ствола. Для длины окружности Cметров и высотыHметров приUV0–1 Tiling=(C,H). На узких ветках уменьшать масштаб рисунка соответственноUV. Мировая трипланарная проекция не добавлялась, чтобы ориентация коры могла следовать изогнутым ветвям черезUV.
Высота/Normal/AO/Roughness приближённо реконструированы из цвета, не измеренный скан. У берёзы тёмный пигмент не равен глубоким трещинам: использована слабая локальная фактура. Художественные диапазоны рельефа2/14/6/5мм для берёзы/тополя/липы/клёна. Height/Parallax визуальные, силуэт не меняют. При искажениях под острым углом уменьшать Height Map/Parallax или отключать. Реальный рисунок коры зависит от возраста дерева; это художественные варианты.
Цвета созданы built-in image_gen, исходники1254², подготовлены2048². Стыки скорректированы обеим осям. Проверки в Validation.json, нормали нормализованы. Подключения карт/компиляция проверены вUnity, сцены/старые материалы/префабы не менялись, Play не запускался. Внешний вид повторов на конкретных мешах проверить вручную.
