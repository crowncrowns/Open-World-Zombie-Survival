# Aged Green Stripe Wallpaper 01
Проект Open-World-Zombie-Survivalgit, Assets/Maps/Buildings/Textures/AgedGreenStripeWallpaper_01.
M_AgedGreenStripeWallpaper_01_URP.mat использует SG_Brick_World: мировая трипланарная проекция, Brick_Tile1 (примерно1×1м), Blend1, Smoothness_Mult1. Орнамент вертикальный на вертикальных стенах, масштаб не зависит отUV/Transform. При перемещении меша рисунок остаётся привязан к миру.
Матовые старые оливковые обои с бежевыми вертикальными растительными полосами, лёгкая грязь/выцветание/редкие потёртости.
8PNG2048²: Surface_BaseColor,Normal_OpenGL,Height16,AO,Roughness,Metallic,MetallicSmoothness,ORM. BaseColorsRGB, прочиеlinear/NormalMap, Repeat/mips/Trilinear/aniso8. Metallic0/Roughness.94.
В мировом материале используютсяBaseColor/Normal/AO/Roughness/Metallic. Height/Parallax SG_Brick_World не поддерживает; картаHeight сохранена отдельно. Рельеф бумаги очень слабый, оценён из мелкой фактуры, не скан; геометрия не меняется.
Цвет built-in image_gen1254² по референсу, пересчитан2048². Края скорректированы; визуальный стык орнамента и масштаб проверить на стенах в сцене. Ошибок шейдера нет, существующие сцены/префабы/материалы не менялись.
