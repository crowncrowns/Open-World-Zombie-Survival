# Российские уличные лавочки

15 префабов находятся в `Prefabs`, обзорная сцена — `Scenes/Demo_Benches_RU.unity`.
Лицевая сторона префабов направлена по +Z, одна единица соответствует метру.

Пять конструкций: ажурная чугунная парковая, сварная дворовая, бетонная,
перфорированная металлическая и простая без спинки. Для каждой существуют Wear01–Wear03.

Все 45 PBR-карт рассчитаны в 4096×4096 без увеличения из 2K. Материалы URP/Lit.
Дерево использует продольный UV0, отдельный UV2 предназначен для lightmap.
Roughness поставляется отдельно; Unity использует Smoothness в alpha MetallicSmoothness.

Исходник: `Source~/Benches_RU_Master.blend`. Относительные пути к текстурам сохранены.
Unity игнорирует папку с суффиксом `~` и не запускает повторный импорт большого исходника.

Сборщик в `Editor` разрешает выполнение только в `work/Benches_RU/UnityProject`.
Для использования готовых префабов запускать его не требуется.

Это процедурная реконструкция по описанию конструкций. AAA, обмерная точность,
производительность большого мира и интеграция в игровую сцену не подтверждены.
Подробные фактические результаты — `Docs/Benches_RU.md` и `Verification/Benches_RU` в проекте.
