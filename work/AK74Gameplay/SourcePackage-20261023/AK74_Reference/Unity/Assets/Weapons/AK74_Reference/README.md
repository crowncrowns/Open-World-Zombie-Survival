# АК-74 по новому референсу

Самостоятельный ассет с металлическим рамочным прикладом и чёрным полимерным цевьём. Модель создана заново по изображению; прежние папки AK74 не использовались. Это процедурная художественная реконструкция, а не обмерная копия или подтверждённый AAA-ассет.

Основной префаб: `Prefabs/AK74_Reference.prefab`. Целевое окружение: Unity 6000.6.3f1, URP 17.6.0.

Корень имеет масштаб 1; единицы — метры. Ствол направлен по локальной +Z, верх — +Y. Дочерний `Visual` компенсирует исходные оси FBX поворотом Y=90°. Один Generic Animator использует общий Avatar из GameReady FBX. Все три LOD связаны с одними костями; HighPoly сохранён отдельно и не входит в игровой префаб. BoxCollider — простая внешняя оболочка предмета, без Rigidbody и игровой логики подбора.

Кости общего Rig: WeaponRoot, Magazine, SpareMagazine, Trigger, Selector, Bolt, Stock. На WeaponRoot находятся Muzzle, Eject, Grip_R, Grip_L, Aim. Компонент AK74Presentation хранит явные ссылки на эти точки. Их окончательная калибровка под руки и камеру конкретного игрока выполняется в системе представления игрока.

## Анимации

Каждому отдельному FBX соответствует одно состояние и одноимённый Trigger в контроллере:

Idle, Fire_Single, Fire_Auto, Reload_Tactical, Reload_Empty, Equip, Unequip, Inspect, Aim_In, Aim_Out, Walk, Run, Sprint, Recoil_Recovery, Bolt_Interaction, Safety_Interaction.

Пример вызова: `animator.SetTrigger("Reload_Tactical")`. Циклические клипы продолжают своё состояние; большинство конечных возвращаются к Idle. Aim_In и Unequip удерживают последнюю позу до следующей команды. Root Motion выключен.

Это анимации самого оружия. Полных рук, персонажа и готового сведения ADS с игровой камерой в пакете нет.

## События и магазин

OnMagazineRemoved скрывает установленный магазин; OnSpareMagazineShown показывает запасной; OnMagazineInserted показывает установленный и скрывает запасной; OnReloadComplete восстанавливает исходное видимое состояние. У каждого магазина есть рендерер во всех трёх LOD. Прерывание состояния и выключение/включение компонента сбрасывают временную видимость. Остальные события огня, затвора и предохранителя доступны как уведомления VisualEvent.

События управляют только представлением. Они не расходуют патроны, не наносят урон и не изменяют инвентарь. Подключение к существующему игровому оружейному backend выполняется отдельно; префаб не регистрирует новый тип предмета автоматически.

Авторский manifest хранит время событий в секундах. Unity ModelImporterClipAnimation хранит нормализованное время, и сборщик выполняет это преобразование при импорте.

## Материалы

Один материал AK74_Atlas использует URP/Lit. Семь карт имеют размер 4096×4096: BaseColor, Normal, Metallic, Roughness, AO, Height, MetallicSmoothness. BaseColor — sRGB; остальные карты — Linear. Normal использует tangent +Y. MetallicSmoothness: R=metallic, A=1−roughness. Height сохранена как дополнительная карта; стандартный URP/Lit префаба не выполняет геометрическое смещение по ней.

Технические проверки и изображения целевого рендера находятся в отчётах основного архива. Проверки в Unity выполнялись в отдельных проектах; пользовательские сцены и параметры освещения ради превью не менялись. Визуальная приёмка, качество окончательного хвата, нагрузка с большим количеством экземпляров и финальная игровая настройка остаются отдельными задачами.
