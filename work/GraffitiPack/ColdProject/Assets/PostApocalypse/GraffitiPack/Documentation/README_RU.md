# Graffiti Pack — Подмосковье после вспышки

60 отдельных композиций: 50 исходных по заданному списку и 10 дополнительных в категории Military2022 («Военная тематика · 2022»). В дополнении: Z, V, O, метки в рамках, СВО 2022, КОЛОННА →, ВОЕННАЯ ПОЛИЦИЯ, БЛОКПОСТ 2022 и многослойная Z/V. Латинские Z/V/O использованы намеренно по запросу пользователя. Рисунки не являются проверенным каталогом исторических подразделений или схем нанесения символов. Изображения созданы встроенным imagegen отдельными запросами; это сгенерированная художественная реконструкция, не фотографии реальной краски и не подтверждение уровня AAA.

## Начало работы

1. Откройте `Tools → Graffiti Painter`. Визуальный каталог содержит все 60 изображений, русские названия, категории и размеры в метрах. Ползунок «Пулевые попадания на мазок» задаёт от 0 до 16 дополнительных случайных следов на клик (по умолчанию 4). Отдельная браузерная галерея: `Documentation/PreviewCatalog.html`.
2. Выберите композицию; выбор подставляет её авторскую ширину. Укажите **Слои стен**. Видимые стены определяются напрямую по MeshFilter/MeshRenderer: Collider и флаг Static не требуются. Terrain определяется через TerrainCollider. Триггеры, Rigidbody (включая kinematic), CharacterController, Animator и объекты самого пака исключаются. Персонаж/неподходящий Collider перед стеной останавливает поиск в выбранных слоях.
3. Включите **Размещение в Scene View**. ЛКМ ставит один экземпляр, Alt сохраняет навигацию, Esc выключает кисть. Никакого автоматического заполнения стен нет. В Prefab Stage и Play рисование отключено.
4. Ширина задаётся в метрах; высота рассчитывается по пропорциям PNG. Поворот — вокруг нормали стены. Непрозрачность — 0–1, без создания материала для каждого мазка. Отступ по нормали по умолчанию 3 мм, диапазон 1–20 мм.
5. Seed и номер успешного мазка определяют случайную последовательность. Случайный выбор действует только в выбранной категории. Независимые разбросы размера/угла/прозрачности можно обнулить. Ползунок **Пулевые попадания на мазок** добавляет от 1 до заданного количества случайных отметин в пределах граффити; 0 отключает слой. Повторные мазки с теми же seed и настройками повторяют выбор, расположение, вариант, размер и угол следов. **Повторить последовательность** сбрасывает номер мазка.
6. Ctrl+Z/Ctrl+Y отменяют и возвращают размещение. Групповое удаление затрагивает только экземпляры с `paintedByTool` в активной сцене и поддерживает Undo. Префабы, галерея и другие сцены не удаляются.

## Случайные следы попаданий

Три варианта прозрачных decals показывают тёмное отверстие, сколы штукатурки и короткие радиальные трещины. При каждом успешном мазке Painter случайно выбирает число следов (от 1 до заданного максимума), вариант, точку внутри отпечатка граффити, размер и поворот. След ставится только если луч находит ту же плоскость стены; Rigidbody/персонажи и проёмы пропускаются. Seed плюс номер мазка полностью определяют результат. Следы — отдельные Quad-объекты с общим материалом и попадают под групповое удаление инструмента и Undo/Redo. Значение 0 оставляет прежнее размещение граффити без изменений.

## Опора и ограничения размещения

Превью показывает изображение и 49 точек проверки прямоугольного отпечатка. Поиск и проверка опоры используют видимый меш, включая здания без Collider и с выключенным Read/Write. Крупный коллайдер корня здания не подменяет плоскость фасада. Слои по умолчанию охватывают всё, кроме Ignore Raycast; при необходимости сузьте маску. После изменения состава объектов можно нажать «Обновить каталог / поверхности». Красные точки означают проём, уступ более 35 мм или несовпадение нормали. По умолчанию такие установки блокируются. Флаг **Разрешить проёмы/рельеф** разрешает художнику установить композицию осознанно.

Это дискретная проверка 7 × 7, а не точная геометрическая обрезка: тонкая щель между точками может остаться незамеченной. Quad не огибает кривую стену. Для сложного рельефа используйте native projector в уже настроенном проекте либо разделите композицию вручную. Превью использует плоский Quad даже при последующей установке projector.

Объекты размещаются самостоятельными корнями сцены, в мировом масштабе: это предотвращает искажение пропорций неравномерным масштабом родительской стены. Они не следуют последующему перемещению стен. Пак рассчитан на статичное окружение; billboard-поворота к камере нет.

## Render Pipeline

Активный Pipeline определяется через QualitySettings, затем GraphicsSettings. В исходном checkout Unity 6000.6.3f1 / URP 17.6.0 профиль Standalone использует `PC_RPAsset`, Renderer `PC_Renderer`; включён SSAO, Decal Renderer Feature отсутствует. Поэтому штатные 60 префабов используют **URP Lit Transparent Quad**. Настройки исходного проекта и Packages не изменяются.

Painter автоматически использует URP/HDRP DecalProjector, если обнаруживает включённую поддержку decals и подходящий shader. URP использует штатный package Decal Shader Graph, `Normal_Blend=0`; HDRP настраивает albedo без воздействия на normal/MAOS. **Всегда использовать Lit Quad** принудительно выбирает совместимый запасной вариант.

Для другого Pipeline после импорта выполните `Tools → Graffiti Pack → Rebuild materials for active pipeline`. Это явная операция над материалами пака с Undo; глобальный рендер не меняется. Встроены ветви Standard/Built-in, URP Lit и HDRP Lit. Подтверждённый Pipeline и фактически выполненные проверки указаны в отчёте; наличие ветви кода не означает проверку HDRP/Built-in.

Quad учитывает освещение и не имеет emission, не отбрасывает тень и не пишет глубину. URP отключает specular/environment reflections материала краски. Alpha сохраняет видимую стену между частицами пигмента. Quad не считывает normal map/roughness исходной стены: на плотных участках краски остаётся собственный плоский normal. Полное сохранение микрорельефа требует native decals и настроенного принимающего материала. Это ограничение совместимого Quad, а не замена материала стены.

При переносе на сильно отличающиеся масштабы/расстояния от камеры проверьте отступ и прозрачную сортировку на месте: 3 мм не являются универсальным доказательством отсутствия мерцания во всём мире.

## Текстуры и оптимизация

Исходники: `Textures/{Warnings,Survivors,Factions,ZombieArt,StreetArt}/G01.png…G50.png`; дополнение — `Textures/Military2022/G51.png…G60.png`. Это 60 самостоятельных RGBA PNG с разными пропорциями, длинная сторона 2048 px. Технический экспорт сохраняет композицию, убирает почти прозрачный шум alpha ≤ 2/255 и добавляет прозрачный запас. Часть выходов imagegen меньше 2048 px и увеличена при экспорте; реальные исходные размеры перечислены в `Verification/GraffitiPack/texture_validation.json` вне пакета. Увеличение не равно дополнительной исходной детализации.

Импортёр действует только внутри `GraffitiPack/Textures`: sRGB, alphaIsTransparency, mipmaps, Trilinear, Clamp, anisotropic 4, Standalone BC7 HQ, без Read/Write. BC7 выбран для desktop; для мобильного проекта назначьте подходящий платформенный формат в копии пакета. Мягкая альфа сохранена; непрозрачной стены/белой подложки в PNG нет.

Каждый обычный экземпляр — один Quad/Renderer, без Collider, анимации и кадрового runtime Update. Один малый компонент хранит каталог/метку удаления и восстанавливает MaterialPropertyBlock непрозрачности при загрузке/OnValidate. Материалы общие для экземпляров одной композиции.

Для плотных сцен предусмотрена явная команда `Tools → Graffiti Pack → Build optional Quad atlases`: по четыре изображения на страницу до 4096, отступ 32 px, общие материалы, собственные UV и альтернативные префабы в `Atlases`. Оригинальные 60 PNG и стандартные префабы сохраняются. PackTextures может уменьшить отдельные изображения; оцените качество mipmaps. Атлас не гарантирует один draw call: прозрачная сортировка, property blocks и условия батчинга зависят от сцены. Atlas-prefabs можно размещать вручную; Painter использует стандартный каталог. Большой мировой FPS этим паком не подтверждён.

## Демонстрация и состав

`Demo/GraffitiGallery.unity` — 60 самостоятельных стен 3 × 3 м, 60 экземпляров, свет и камера каталога. Высокие композиции в демонстрации равномерно уменьшены до 2,85 м внутри модуля. Авторский размер каждого оригинального префаба остаётся в каталоге. `Demo/IsolatedURP.asset` и Renderer предназначены для изолированной демонстрации; сцена сама не переназначает Pipeline пользователя.

`Catalog/G01.asset…G60.asset` содержит ссылки и размеры. `Materials` и `Prefabs` имеют читаемые русские имена с номером. Префабы независимы. Полный перечень путей и размеры — `Documentation/catalog.json` и внешний отчёт/asset_manifest.json.

Импортируйте `.unitypackage` в совместимый URP-проект с URP 17.6.0. Пользовательские сцены, механики игрока, сохранения и застройка этим паком не меняются. Художественная приёмка в целевых игровых локациях остаётся отдельной работой.
