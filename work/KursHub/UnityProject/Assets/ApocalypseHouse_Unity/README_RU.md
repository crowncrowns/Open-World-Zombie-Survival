# Apocalypse House 6×6 — игровой ассет для Unity + исходник Blender

**Содержимое:** игровая модель одноэтажного постапокалиптического кирпичного дома с полноценно смоделированными помещениями и окружающим антуражем. Все размеры даны в **метрах**, оси экспортов **Unity Y-up** (Y — высота), фасад с входом ориентирован на -Z. Точка отсчёта модели — центр дома на высоте земли. Модель художественная и предназначена для игры, **не строительная документация**.

## Файлы

- `Apocalypse_House_Unity_OPTIMIZED.obj` + `Apocalypse_House_Unity_OPTIMIZED.mtl` + PNG текстуры рядом — **самый простой импорт в Unity** без дополнительных плагинов. Это объединённая по материалам/категориям версия, ~85 mesh-объектов.
- `Apocalypse_House_Unity_OPTIMIZED.glb` — оптимизированный glTF 2.0, сохранены UV, материалы и названия. Для Unity потребуется импортёр glTF (например glTFast).
- `Apocalypse_House_Unity.glb` — **полный редактируемый исходник**: ~633 отдельных mesh-объекта, включая деревянные балки, окна, двери, мебель, ящики, инструменты и т.д. Импортировать в Blender через *File → Import → glTF 2.0*.
- `Apocalypse_House_Unity.obj` + `.mtl` — альтернативный детализированный вариант Wavefront OBJ для прямого импорта в Unity/Blender.
- `Blender/create_blend.py` — создаёт обычный `.blend` из полного исходника и группирует объекты по коллекциям.
- `Unity/Editor/ApocalypseHousePrefabBuilder.cs` — инструмент редактора Unity для сборки prefab с базовыми коллизиями.
- `generate_house.py`, `optimize_for_unity.py` — процедурные исходники генерации/оптимизации; требуются Python, NumPy, Pillow, trimesh.
- `Blender/Exterior_Concept_Reference.png` и `Blender/Concept_Layout_Reference.png` — исходные концепт-изображения (не текстуры/UV).

## Быстрый импорт в Unity

1. Перенеси `.obj`, соответствующий `.mtl` и **все PNG-текстуры из корня архива** в одну папку внутри `Assets/ApocalypseHouse/Model/` (можно просто перетащить содержимое целиком).
2. Выбери `Apocalypse_House_Unity_OPTIMIZED.obj` в окне Project. В Inspector проверь `Scale Factor = 1` и совпадение с размерами: габарит самого дома 6×6 м, от земли до конька 6 м. Сцена вместе с окружением шире: около 16×17 м.
3. Перетащи модель в сцену. При необходимости создай материалы Unity Standard/URP/HDRP и назначь карты `brick.png`, `slate.png`, `wood.png` и остальные в Base Map / Albedo, если Unity не связала их автоматически через `.mtl`.
4. Чтобы добавить базовые коллизии, скопируй `Unity/Editor/ApocalypseHousePrefabBuilder.cs` в `Assets/Editor/`, выдели импортированный OBJ в Project и нажми **Tools → Apocalypse House → Create Prefab With Colliders**. Получишь `Assets/ApocalypseHouse/Apocalypse_House_GameReady.prefab`.
5. Расставь точку спавна перед крыльцом (примерно X=0, Y=0.2, Z=-5.7). Для ходьбы по дому используй своего CharacterController/Rigidbody.

**Важно:** у OBJ нет полноценной иерархии/локальных pivot в формате файла; для анимации дверей удобнее взять оригинальный GLB, а в Unity создать/проверить локальный pivot на петле двери. Для использования GLB может понадобиться glTF-импортёр. Рекомендуется генерировать на сцене статические коллайдеры, а не convex Rigidbody на весь дом. Для мобильной версии можно отключить `Environment`, `Roof_Details`, мелкий мусор и часть припасов.

## Как получить редактируемый файл `.blend`

**Вариант без скрипта:** в Blender выбери **File → Import → glTF 2.0 (.glb)** → `Apocalypse_House_Unity.glb`, затем **File → Save As…** → `Apocalypse_House_Unity.blend`.

**Автоматически (Blender должен быть установлен):**

```bash
blender --background --python Blender/create_blend.py
```

Команду выполнить из каталога архива. Она импортирует исходный детализированный GLB, создаст коллекции для разных элементов сцены, камеру и освещение, а затем сохранит `Apocalypse_House_Unity.blend` рядом с моделью.

## Ограничения исходного ассета

- Это **процедурный игровой блок-аут с текстурами и деталями**, а не точная скульптура по фотограмметрии. Обстановка, геометрия и материалы передают концепцию, но не повторяют каждый предмет на рендере 1:1.
- Предполагается дальнейшая доводка в Blender: дополнительные сколы, UV-упаковка, роспись текстур, Lightmap UV, LOD, упрощение коллизий.
- В версии GLB/OBJ нет запрограммированных функций взаимодействия. Открывание дверей, свет, генератор, зомби и лут добавляются твоими Unity-компонентами.
- Часть мелкого окружения намеренно оставлена отдельными объектами и категориями, чтобы её можно было отключать.
- Генератор, стоящий в погребе, подразумевается **выключенным на хранении**; работающий генератор следует держать снаружи, иначе угарный газ быстро превращает сценарий выживания в финальные титры.
