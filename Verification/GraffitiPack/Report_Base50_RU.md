Маска по умолчанию — все слои, кроме Ignore Raycast; для уже открытого окна после обновления проверьте «Слои стен» или закройте и откройте Painter заново.

## Подтверждённая конфигурация

Unity 6000.6.3f1, URP 17.6.0, desktop. В исходном проекте выбран профиль качества с `PC_RPAsset` / `PC_Renderer`; Decal Renderer Feature отсутствует. Основные префабы используют освещаемый URP Lit Transparent Quad, alpha blend, без emission, без ShadowCaster и записи в depth. Материал исходной стены не заменяется. Нормаль Quad выравнивается по поверхности, pivot находится в центре. Авторские ширины 0,55–3 м; высота рассчитывается по пропорциям. Длинная сторона каждой итоговой PNG — 2048 px; пропорции различаются (46 горизонтальных, 4 вертикальных).

Настройки GraphicsSettings/QualitySettings/Packages исходного checkout инструментом не менялись. Pipeline демонстрации создавался только внутри изолированного проекта. Для HDRP/Built-in предусмотрены ветви материалов и явная команда перестройки, однако их импорт/рендер в этом проходе не проверялись. Подтверждённая совместимость переносимого архива — URP 17.6.0.

## Работа с инструментом

Открытие — `Tools → Graffiti Painter`. Каталог всех 50 вариантов, превью, установка ЛКМ по Collider, LayerMask, поиск видимых мешей без обязательных Collider/Static, нормаль поверхности, метры, поворот, opacity, Seed, случайный выбор в категории и три разброса. Alt оставляет навигацию, Esc выключает кисть. Проверка 49 точек показывает красным проёмы/перепады и блокирует установку, если художник явно не разрешил частичную опору. Undo/Redo и групповое удаление только собственных меток активной сцены; authored-галерея и другие сцены сохраняются.

Если текущий Renderer уже поддерживает decals, Painter выбирает native URP/HDRP projector; можно принудительно выбрать Lit Quad. Инструмент не включает Renderer Feature и не правит Pipeline пользователя. Runtime-покадровой логики нет; компонент только хранит данные и восстанавливает opacity при загрузке/OnValidate.

Команда атласов: `Tools → Graffiti Pack → Build optional Quad atlases`. Проверочные атласы созданы за пределами пака (`work/GraffitiPack/UnityProject/Assets/GraffitiAtlasVerification`) и не входят в поставку. Команда остаётся в паке; исходные 50 PNG сохраняются. PackTextures может уменьшать разрешение; UV/ссылки проверены, отдельная визуальная и FPS-приёмка атласного режима не проводилась.

## Художественная проверка и ограничения

Изображения получены отдельными запросами встроенного imagegen, не извлечены из одного коллажа. Все 40 текстовых композиций сверены визуально с русским списком; 10 хоррор-композиций не содержат подписей. «ДОМОЙ УЖЕ НЕЛЬЗЯ» отдельно исправлена: добавлен пропущенный панельный дом. У «ЖИВЫЕ СТРАШНЕЕ» использована неграфическая версия двух лиц после отказа генератора первого результата.

48 исходных выходов генератора имели длинную сторону менее 2048 px. Экспорт добавил прозрачные поля, убрал почти прозрачный шум alpha ≤ 2/255 и привёл итоговые файлы к 2048 px. Это техническое увеличение, а не нативная новая детализация. Исходные размеры и признаки касания края исходника раскрыты в texture_validation.json; прозрачные поля не восстанавливают отсутствовавшие в исходнике штрихи.

Совместимый Quad сохраняет стену между частицами пигмента, но не наследует её normal map/roughness на плотных участках. Для полноценного сохранения микрорельефа нужны native decals в соответствующем Renderer; их GPU-вид в этом проходе отдельно не принимался. Превью остаётся плоским Quad. Сетка 7 × 7 может пропустить тонкие щели; она не является точной обрезкой геометрии. На кривых стенах Quad может отставать от поверхности. Размещённые объекты являются мировыми корнями и не следуют последующему перемещению стены.

Отсутствие мерцания на всех дистанциях/камерах/поверхностях не доказано несколькими кадрами. Не подтверждены AAA/точное совпадение референсу, FPS большого мира, standalone build, основной Play, игровой свет/погода и world-save интеграция. Пользовательская художественная приёмка на игровых стенах остаётся отдельным этапом.
