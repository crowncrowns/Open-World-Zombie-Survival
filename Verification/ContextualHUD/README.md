Проверены:

- Чистый экран при полных запасах, отсутствие постоянного прицела и старого Canvas поверх нового.

- Перестроение панели для 10 и 1 слота.

В ходе запуска редактора отмечено отдельное исключение `ArgumentOutOfRangeException` внутри `UnityEditor.Search.SearchDatabase.EnumerateAll/GetDefaultSearchDatabase`. Оно записано в отчёте как `EDITOR_SEARCH_EXCEPTION`; игровой probe продолжал проверку. Поэтому вся Console не объявляется полностью чистой. Ошибки компиляции и ошибки/assertions игрового HUD в успешном прогоне отсутствуют. Предшествующие предупреждения obsolete API сторонних Editor-скриптов не исправлялись в этой задаче.
