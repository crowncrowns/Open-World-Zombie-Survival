# Игрок Survivalist и анимации UAL

Предпросмотр рюкзака (21.10.2026): [InventoryPresentation.md](InventoryPresentation.md). Используется только отдельная визуальная копия `PlayerVisual.ModelPrefab` с тем же Avatar и явным Idle_Loop. Все игровые MonoBehaviour/физика/звук удаляются до активации, AnimationEvents/root motion выключены; основной PlayerUALAnimationDriver и HeldWeapon не клонируются. Эта витрина не меняет HIP/ADS и анимацию настоящего игрока.

Изменение от 20.10.2026, калибровка пистолета обновлена 21.10.2026: [PlayerPistolPresentation.md](PlayerPistolPresentation.md). Рабочие объекты: игроки CharacterTest, Maps/Interior/Interiors и `Assets/CharacterTesting/Prefabs/CharacterTestPlayer.prefab`. Внешний вид — `Assets/Characters/PlayerUAL/SurvivalistPlayer.prefab`, контроллер — `SurvivalistUAL.controller` в той же папке. Подключены 22 различных клипа UAL и три вспомогательные позы пальцев. Остальные сцены автоматически на новую модель не переводятся.

## Подключённые действия

| Механика | Клип / способ |
|---|---|
| Ожидание | Idle_Loop |
| Медленный шаг | Walk_Formal_Loop |
| Обычное движение | Walk_Loop → Jog_Fwd_Loop по реальной скорости |
| Бег | Sprint_Loop |
| Присядь: стояние / движение | Crouch_Idle_Loop / Crouch_Fwd_Loop |
| Прыжок, полёт, приземление | Jump_Start / Jump_Loop / Jump_Land |
| Перекат | Roll, время согласовано с ParkourProgress |
| Подтягивание / преодоление / вис | ClimbUp_1m из UAL 2; поза рук дополнительно корректируется прежним паркурным IK |
| Пистолет | Pistol_Idle_Loop, Pistol_Aim_Up/Neutral/Down, Pistol_Shoot, Pistol_Reload |
| Топор | Sword_Idle / Sword_Attack с согласованием замаха |
| Успешный подбор с пола | PickUp_Table; проигрывается после подтверждённого WorldItem-взаимодействия |
| Смерть | Death01 |
| Ползание | Прежний PlayerCrawlAnimation: в UAL 1/2 клипа ползания нет |

Отдельных strafe/backward-клипов в этих двух наборах нет. PlayerUALAnimatorIK приблизительно перенаправляет траектории шагов на восемь направлений, с ограничением коррекции стоп до 0,3 м и поворота до 35°. Он не закрепляет стопу в мировых координатах. Это приближение; для точных боковых/обратных циклов понадобятся дополнительные анимации.

## Устройство и правила интеграции

- PlayerUALAnimationDriver на корне читает фактическую скорость CharacterController и существующие состояния FirstPersonController/PlayerParkour. `PlayerVisual.driveAnimator=false`, чтобы прежний драйвер не конкурировал с новым. Root Motion выключен; скорость, коллизии и перемещение по-прежнему задаёт игровой контроллер.
- Действия рук находятся в masked слое Upper Body только для рук/пальцев; корпус и голова исключены, движение ног не заменяется. Слой Hand Grip содержит только позы пальцев для удержания оружия. Эти небольшие вспомогательные позы созданы в проекте, основные движения взяты из UAL.
- PlayerWeapons сообщает о принятых действиях через ShotFired/SwingStarted/ReloadStarted/WeaponEquipped. Боеприпасы, урон, прочность, время перезарядки и замаха остаются в существующей игровой логике. Animation Events не наносят урон и не расходуют предметы. Отказанное действие не запускает повторный выстрел.
- `handBoundVisual` включает единственную модель HeldWeapon на RightHand. Для старых игроков значение по умолчанию false сохраняет прежнее крепление к камере. Не добавлять второй экземпляр пистолета на камеру. Положение и углы хвата настраиваются в PlayerWeapons.
- Калибровка RightHand Survivalist: пистолет Position=(0.19,-0.045,0.03), Euler=(90,0,0); топор Position=(0.16,0,0.13), Euler=(90,35,0). Готовность топора корректирует только правую руку в AxeIdle; во время принятого удара IK сразу освобождается. ADS и готовность используют постоянное преобразование осей кости в Humanoid goal, определяемое на первом базовом IK-проходе; не вычислять поправку повторно из результата предыдущего кадра/слоя. Дальность вытягивания рук ограничена 95% длины конечности.
- При беге/паркуре/ползании/меню ручной IK не действует. После WorldStateRestored/Revived/Died сбрасываются триггеры, Animator и временные веса IK. `shortNameHash` используется для Pickup/AxeIdle: сравнение `IsName("Pickup")` без пути слоя здесь не подходит. Pickup проверяется также в следующем состоянии перехода, чтобы слой успел включиться.
- HIP и ADS используют единую целевую позу оружия относительно камеры и обратный расчёт обеих кистей из того же mount/grip. Пистолет следует pitch также без ПКМ. Прежнее отпускание IK при взгляде вверх отменено; руки ограничены достижимостью, а Upper Body mask исключает наклон корпуса. Подробный контракт и границы — [PlayerPistolPresentation.md](PlayerPistolPresentation.md).
- При handBoundVisual сохраняется сглаживание aimWeight для игрового muzzleOffset→aimMuzzleOffset. У стены HeldWeapon скрывается тем же ближним Cast, что раньше использовался для опускания camera-модели; это только представление.
- Исходные FBX UAL и Survivalist не изменены. В Sources лежат отдельные Humanoid-копии стандартных, не RM, файлов. Их клипы имеют запечённое перемещение корня, циклы настроены для Loop-клипов.
- В исходном Avatar Survivalist Hips ошибочно указывает на `root` у пола. Авторская копия Sources/SurvivalistRig.fbx исправляет Hips на `pelvis`; не возвращать исходный Avatar только потому, что Unity считает его valid. Модель автора смотрит в −Z: внутри визуального префаба сохранён поворот 180°.
- Отключены дополнительные FPS Arms исходного Survivalist, чтобы не получать двойные руки. Тело целиком видно от первого лица; только меши головы/головного убора скрываются для камеры игрока через PlayerModelDefinition и существующий PlayerVisual. Снаружи голова и полная тень остаются. Не отключать голову глобально и не переносить всё тело в отдельный слой, невидимый игроку.
- PlayerVisual.localPosition=(0,0,0). Базовая камера (0,1.65,0.10), вверх85°/вниз70°, downwardCameraShift=0.13 после25° взгляда вниз с ограничением XZ сечением капсулы и зазором0.02м. Позиция каждый кадр от базы, без накопления; default shift0/downLimit85 сохраняют прежних игроков. Look вычисляется до posture, а Load сначала clamp pitch, затем положение. Физическая капсула и gameplay проверки не заменяются.
- Смена модели требует совместимого Humanoid Avatar и явных Head Renderers. Новый драйвер переподключает Animator/IK при замене модели. Procedural crawl и прежний PlayerParkourHandIK сохранены; новый IK не вмешивается в их состояния.
- После обновления source player prefab и сценового override проверить VisualRoot: должен остаться один обслуживаемый SurvivalistPlayer. Setup удаляет только лишние экземпляры собственного VisualPath, не произвольные пользовательские дочерние объекты. Был обнаружен и устранён такой дубль; прежние картинки с двойными конечностями не были дефектом клипов или GPU.
- Сохранения не получают новых полей анимации; поза восстанавливается из состояния игры. Не сохранять триггеры Animator и не менять ID игрока/предметов ради внешнего вида.

## Проверки и дальнейшая работа

PlayerUALChecks и PlayerUALVisualChecks предназначены только для отдельного проекта в `_CodexRecovery` и отказываются запускать сценарии в основном проекте. Они не должны становиться runtime-компонентами. PlayerUALSetup выполняет нативное создание/настройку ресурсов в Edit; CreateController намеренно отказывается перезаписывать существующий контроллер. Не удалять контроллер для обхода этого ограничения: вносить точечные правки через Animator/Editor API.

При дальнейших изменениях проверить все восемь направлений в обычном/медленном/быстром/присевшем движении, переходы в ползание, прыжок, принятый и отказанный выстрел, перезарядку, удар, закрытие меню и восстановление состояния. Отдельно осматривать тело вниз, хват обоих видов оружия и экстремальный наклон камеры. Недостаточно проверить только компиляцию или `Avatar.isValid`.

В новых изменениях второго разработчика добавлены ProBuilder 6.1.3 и отдельная сцена Interiors. Пакеты и застройка сохранены. В Interiors обнаружена лишняя корневая Main Camera вместе с Main Camera игрока: корневые Camera и AudioListener отключены, не удалены, чтобы изображение и звук управлялись игроком. В основной сцене Play ради проверки не запускался. Резервные копии открытых сцен и исходного префаба — `S:/Games/Unity Projects/_CodexRecovery/PlayerUAL-20261020`.

Оригинал ItemStack, ID, патроны и прочность при замене модели сохранены. Это проверка lifecycle анимаций, а не повторная полная проверка мировых save-файлов.
