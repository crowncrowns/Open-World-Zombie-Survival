# Широкое трёхстворчатое окно — 24.10.2026

Prefab: Assets/Maps/Buildings/Walls/Prefabs/Outside/TripleWindow/Wall_Window_Triple_Interactive.prefab.
Стена строго3×3×0,4м, rootScale1. Окно1,8×1,2м, центрY1,5м. Отлив и оконная фурнитура выступают за плоскость стены так же, как у исходного окна:0,4м — толщина стенового блока, не общий bounding box отлива.

Основа — актуальный Wall_Window_Interactive. Использованы его ссылки на материалы: WeatheredRedBrick_01/SG_Brick_World.shadergraph (встроенный материал), AgedPVCWindow_01/M_AgedPVCWindow_01_URP.mat, RustyWindowSill_01/M_RustyWindowSill_01_URP.mat, DirtyHazyGlass_01/M_Glass_DirtyHazy.mat. Ни один исходный материал не менялся. Створки, ручки/петли и стекло получены из его mesh: форма/размеры сохранены, мировые преобразования запечены в отдельные mesh assets. Центр — копия рамы/стекла без ручки и петель, неподвижная. Наружная рама с фасками/два импоста и левая поперечина созданы отдельно тем же PVC-материалом. Отлив расширен. Это самостоятельный производный prefab, не linked variant, изменения исходной геометрии автоматически не переносятся.

Две крайние створки интерактивны через существующий ZombieSurvival.Interaction.DoorInteractable: шарниры у наружных краёв,90°,скорость100°/с,выбор стороны по игроку,проверка препятствий,открыть/закрыть через штатный Interact/E. В сохранённом исходном prefab MonoBehaviour открывания отсутствует — компонент подключён к новому prefab без изменения чужого кода. Средняя секция fixedCollider. Все основные стеклопакеты физически блокируют закрытый проём. Коллайдеры стены состоят из4частей вокруг проёма, сквозного полного коллайдера нет.

Для размещения: drag prefab в сцену вместо модуля стены3×3×0,4,Scale1; не накладывать поверх активного коллайдера сплошной стены. Взгляд с -Z — внутренний вид. Сцены/Player/оригинальный prefab/FBX/материалы/скрипты не менялись; новый prefab выделен в Project. Сохранение в world-save автоматически не подключено: использовать стандартный авторинг по Docs/WorldSaving.md с уникальными IDs, не дублировать IDs вручную.

Проверки в Unity6000.6.3f1 EditMode в отдельной preview-scene: стеновой bounds(3,3,0.4);ровно2DoorInteractable с назначенными hinge/leaf; поворот обеих створок в обе стороны0…90° с шагом1° не даёт проникновений в статические/чужие коллайдеры более6мм. Исправлены pivot и зазор импостов. Настоящие URP-рендеры закрытого/открытого варианта просмотрены. Это статическая проверка геометрии/подключений, реальное нажатие E/движение в Play пока не проверялось. На ближнем столкновении с игроком штатный компонент может остановить створку — это предусмотренная проверка препятствий.

Ручная приёмка: разместить на стене, E открыть/закрыть левую и правую независимо, обе вместе, с двух сторон; проверить реакцию на препятствие, вид стекла при дневном свете, стык отлива со стеной.
