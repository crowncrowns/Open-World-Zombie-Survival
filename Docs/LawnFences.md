# Низкое газонное ограждение по фотографии

Авторский комплект 23.10.2026: `Assets/Environment/Fences`. Исходник — одна фотография низкого дворового ограждения. Это процедурная реконструкция пропорций, не фотограмметрия и не измеренная копия. Художественный уровень AAA не сертифицирован.

Повторная проверка 24.10.2026: модели и текстуры восстановлены из сохранённого UnityPackage с побайтным сравнением; редактируемые Blender-исходники пересозданы исходным авторским генератором. Проверки выполняются в отдельном `work/LawnFence/UnityProject`, без запуска пользовательских сцен.

## Состав и размещение

Пять отдельных FBX и префабов: `PF_Fence_Intact`, `PF_Fence_Broken_Rods`, `PF_Fence_Bent`, `PF_Fence_Heavy_Rust`, `PF_Fence_Destroyed`. Три LOD в каждой модели; отдельные низкополигональные коллизионные FBX, материалы URP/Lit. Rigidbody и игровые скрипты не нужны.

Шаг секции — **1,8 м**, центральная высота верхней дуги — **0,515 м**, край — **0,43 м**, нижняя перекладина — **0,115 м**. Прутья диаметром 10 мм, верхняя перекладина 15 мм, нижняя 14 мм, стойка 26 мм. Pivot на уровне земли у начала секции. Масштаб префаба `(1,1,1)`.

Каждая секция включает **только левую опору**. Следующую секцию ставить её `Socket_Start` в `Socket_End` предыдущей. Для прямого ряда координаты X: 0 / 1,8 / 3,6 / … . Последний открытый конец закрывается отдельным `PF_Fence_EndPost`. Таким образом на прямых стыках нет сдвоенных стоек. Поворачивать новую секцию вокруг её начала; очень острые углы требуют ручной проверки примыкания круглых перекладин. Сокеты номинальные; полностью разрушенная секция намеренно не образует непрерывную линию. Существующие карты автоматически не заполняются.

`LeftSupport` — отдельный дочерний объект, при специальной ручной сборке его можно отключить. У Bent опора немного наклонена, у Destroyed лежит вместе с повреждённой секцией. Закрывающий префаб по умолчанию с умеренным износом; для ржавого окончания назначить `MAT_Fence_Heavy_Rust`.

## Геометрия, поверхности и ограничения

Верхняя дуга и повреждения сделаны геометрией. Закрытые круглые профили, неровные торцы, небольшие сварные валики. Сварные узлы состоят из пересекающихся замкнутых оболочек; это не единый сваренный CAD solid. В сломанной секции отсутствует один прут, другой оборван, третий отогнут. У разрушенной секции разрыв верхней перекладины, искривлённые прутья и два отдельных металлических обломка. Мелкие торцы и коррозионный разрыв — художественная реконструкция, не физическая симуляция разрушения.

Два набора текстур **4096×4096**: Old и Heavy_Rust. Отдельно Albedo, tangent-space Normal, Metallic, Roughness, AO, Height; для URP упакована MetallicSmoothness (R = metallic, A = 1−roughness). AO подключён отдельной картой. HDRP не используется. Height поставляется как исходная информация и не создаёт displacement в URP/Lit. AO описывает микровпадины поверхности, это не запечённая уникальная AO всей секции. UV0 — полосовая развёртка круглых деталей с разными смещениями по общей поверхности; допускается повторное использование участков атласа. UV1 генерируется импортёром Unity для освещения.

Краска, ржавчина, мелкие сколы, царапины и грязь получены процедурно. Отдельный набор Heavy_Rust используется для сильной коррозии и разрушения, Old — для целой, сломанной и погнутой секций. Материал не содержит фотографической текстуры самого референса. Сильные различия состояния обеспечиваются геометрией и двумя степенями износа; индивидуальных уникально запечённых карт на каждый вариант нет.

Коллайдер секции — статический невыпуклый MeshCollider по упрощённым круглым деталям: просветы между прутьями остаются открытыми. У стойки CapsuleCollider; не включать convex для всего открытого каркаса. Тонкие прутья не заменяют отдельного проектирования навигации NPC. NavMesh не изменялся.

LODGroup: пороги относительной высоты на экране 0,16 / 0,065 / 0,012; далее отсечение. Сварные валики убраны в LOD2. Точки концов секций сохраняются. Исходники `.blend` лежат в `Sources/LawnFence`, генераторы — `Tools/LawnFence` вне импортируемого Assets. Для переносимости сохранять папки Sources и Assets относительно общего корня архива.

## Проверка

Доказательства — `Verification/LawnFence`: Blender re-import, число полигонов, проверка Unity и изображения. Проверочный проект — `work/LawnFence/UnityProject`, Unity 6000.6.3f1 + URP 17.6.0. Не открывать этот checkout вторым редактором ради теста.

Сцена `Assets/Environment/Fences/Demo/LawnFence_Daylight.unity` содержит пять секций в ряд, отдельную конечную стойку, дневной свет, старую дорожку и траву. Декорации находятся только в Demo, не в префабах. Она не добавляется автоматически в Build Settings и не меняет CharacterTest/SampleScene.

Технические проверки не доказывают AAA-качество, точное совпадение с фото, производительность массового размещения, поведение игрока/NPC или результат запечённого освещения в пользовательском мире. Для игровой приёмки отдельно пройти вдоль секций с расстояния 0,5–2 м, проверить переключения LOD на целевой камере и коллизии реального контроллера, затем оценить нагрузку при массовом размещении.
