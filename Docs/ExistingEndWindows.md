# Торцевые окна в существующих домах

Обновлены пять экземпляров Building_test-house-004 и его копий (1)–(4) в SampleScene_TerrainRoads. Каждый — 5 этажей, 3 подъезда. Добавлено 100 окон: по два на каждом этаже обоих торцов, всего 50 торцевых групп.

Дома целиком не пересоздавались. Существующие LeftEnd/RightEnd и их дочерние объекты сохранены. У исходных Wall_Solid_Mesh отключены только MeshRenderer и BoxCollider; под каждым торцом добавлена группа EndWindows с окнами и крайними глухими вставками. Прежние материалы боковой стены и текущие материалы рам из того же дома сохранены. Стекло и оконные компоненты происходят из существующего шаблона.

Перед операцией сохранены дисковая версия сцены и две копии живой сцены со всеми несохранёнными пользовательскими правками. После операции проверены сериализованные состояния 273457 существующих объектов/компонентов всей сцены. Изменения разрешены только спискам детей торцов, enabled сплошных стен/коллайдеров и флагу версии торцевых окон; остальные поля и ссылки совпадают. Ни один существующий объект не удалён. Двери, ManualContent, фасады, лестницы, материалы, позиции/повороты/масштабы, дороги и Terrain не перезаписывались ради генерации.

У новых окон устранены наложения мешей: SeamUnion получил режим изменения только заданных новых MeshFilter; существующие меши используются лишь как границы и никогда не заменяются. Для проверки применяется локальная матрица иерархии без вычитания больших мировых координат. В отдельной копии реальной живой сцены: 0 наложений до и после у всех пяти домов, 0 нечитаемых мешей, Undo/Redo с готовыми mesh/material references, повторное применение без дублей, сохранение/открытие сцены и коллизии окон PASS. В основном Editor операция прошла ту же проверку сохранности объектов, затем сцена сохранена. Повторная живая проверка: 5 домов, по 10 групп, 0 ошибок окон, 34 корня, dirty=False.

Три ранее изменённых пользователем материала на диске побайтно неизменны. Ранее существовавшие одинаковые buildingId у копий не изменялись. Сквозная проверка уникальности игровых ID не заявляется; Play не запускался. Коммит/push не выполнялись.

Сцена сохранена вместе с текущими ручными правками. Операция доступна в Undo.
