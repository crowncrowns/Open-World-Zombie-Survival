# Торцевые окна и единая наружная отделка

Tools → Zombie Survival → Модульные дома MVP.

## Новые дома

При генерации профилей V4 (9 м) и V5 (15 м) на каждом этаже каждого наружного торца создаются два окна из существующего Wall_Window_Interactive. Масштаб окон 1; оригинальные рамы, стёкла и материалы сохранены. Два средних модуля по 3 м — оконные, крайние глухие по 2,8 м; общий прежний торцевой пролёт 11,6 м сохранён. Левый и правый торцы ориентированы наружу. Между подъездами наружные торцы не создаются. Коллизии закрытых окон сохранены.

Новое правило проверяется при Validate у новых домов. Существующие сохранённые дома не мигрируют автоматически; для нового варианта используйте новый постоянный ID и Preview/Generate. Старые профили и Review сцены не перезаписываются. Название исходного оконного prefab не означает добавление новой логики открывания: его исходные компоненты сохранены как есть.

## Общий материал

Поле **Материал наружных стен** задаёт отделку для Preview/Generate. Пусто — материал профиля. Галочка **Включая входные двери** также меняет полотна и коробки входных дверей.

Для уже стоящего дома:
1. Выберите корень дома либо его дочерний объект в Hierarchy.
2. В окне генератора нажмите **Взять выбранный дом**, либо перетащите корень в поле **Дом**.
3. Назначьте **Материал наружных стен**; выберите, включать ли входные двери.
4. Нажмите **Применить материал ко всем наружным стенам**, затем сохраните сцену Ctrl+S.

Обрабатываются передний/задний фасады, обе боковые стены, стенки входных проёмов, четыре угловых добора и цоколь. Можно явно выбрать материал другого шейдера, например URP Lit; исходный профиль не изменяется. При пустом override генератор сохраняет прежнее требование профиля к World Space shader.

Стёкла, оконные рамы и отливы, ручки/петли/замки, квартирные двери, внутренняя облицовка, перекрытия, кровля и вентиляция сохраняют материалы. Меняются ссылки sharedMaterials только на экземплярах дома; сами материалы и исходные prefab не редактируются. Геометрия не пересоздаётся. Undo/Redo поддерживаются. Если после применения снять галочку дверей и применить снова, двери получают сохранённые прежние материалы экземпляра. Это сохранение работает и после Save Prefab.

## Проверка

Unity 6000.6.3f1: основной Editor компилируется без ошибок. В отдельной копии проекта пройдены полные BuildingGenerator.Validate для V4 1F/1E, V4 3F/2E, V5 3F/2E и V5 5F/4E; включает геометрию, маршруты, отсутствие coplanar overlap и новую проверку обоих торцов. Для 5F/4E добавляются 20 торцевых окон; всего 216 закрытых оконных коллизий.

Проверены произвольный URP Lit материал стен/входных дверей, неизменность прочих материалов и поз, Undo/Redo, восстановление прежних дверей, сохранение prefab и его обратных ссылок, отрицательные проверки скрытого окна и неверного материала. Материальная правка старого prefab V5 не меняет количество объектов или версию правила торцевых окон. Native URP render обоих торцов выполнен отдельно. Открытая пользовательская сцена, три пользовательских материала, исходные префабы и профиль не пересохранялись. Игровой Play не запускался.

Результаты: Verification/BuildingExteriorControls/checks.txt. Проверочные команды выполнялись только в отдельном проекте; их временные скрипты находятся в work текущего чата. Коммит и push для этой задачи не выполнялись.
