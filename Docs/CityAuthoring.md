# Инструменты города — этап Г1: каталог и план квартала

25.10.2026. Окно: **Tools → Zombie Survival → Город — планировка квартала**.

Дополнение той же даты: **[Городские дома V6](CityBuildingsV6.md)** — новый профиль до 16 этажей / 6 подъездов, квартиры, балконы, кровля и водостоки. В StarterBuildingCatalog добавлен тип residential-v6; прежние профили/участки сохраняются. Ограничения 1–9 ниже относятся к исходному Г1 с V4/V5, а не к V6.

## Назначение

Каталог хранит доступные типы зданий: проверенные BuildingSeriesProfile существующего модульного генератора или готовые статические prefab. План квартала хранит участки, мировые позы и постоянные авторские ID. Инструмент создаёт только один явно выбранный дом; автоматической перестройки города нет.

## Как пользоваться

1. Открыть окно и нажать «Новый каталог». Выбрать путь asset. Если в проекте есть DemoProfileV5, он включается как первый тип; это демонстрационный шаблон, не каталог реальных серий Видного.
2. В Inspector каталога добавить типы с уникальными ключами, понятными названиями и ссылками. Для готового prefab задать размер корпуса X/Z и смещение центра корпуса относительно корня. Не добавлять NPC, лут и сохраняемые игровые объекты.
3. Нажать «Новый план». Назначить каталог, добавить участок, выбрать тип здания. Запись плана не создаёт объектов сцены.
4. Указать центр участка, поворот, полный размер с запасом под лестницы и свесы. Для модульного профиля — год, этажи и подъезды. Y означает уровень пола первого этажа. «Взять высоту Terrain в центре» меняет только Y в записи плана; не выравнивает Terrain и не проверяет перепад по периметру. Участок можно передвинуть ручкой в Scene.
5. «Проверить план» проверяет данные и конфликты. «Предпросмотр выбранного дома» строит один дом в отдельной Preview Scene и показывает его в окне.
6. Только «Создать выбранный дом (Undo)» добавляет новый корень в активную обычную сцену. Сцена не сохраняется автоматически. Существующий участок повторно создать нельзя. Удаление записи из плана не удаляет уже размещённое здание.

Параметры плана сохраняются в asset стандартным сохранением проекта. Копирование участка кнопкой окна выдаёт новый ID; копирование самого plan asset сохраняет прежний planId — для независимого плана нужно назначить новый ID ДО размещения. ID опубликованного плана/участка менять нельзя.

## Границы первой версии

- Используется прежний BuildingGenerator и его Preflight. Поддержка U-9x12/U-15x12, диапазонов этажей/подъездов и геометрии не расширена.
- Проверяются пересечения прямоугольных участков в XZ с учётом поворота, включая соседние участки плана. Касание границ допускается. Для существующих GeneratedBuilding используется консервативный XZ bounds, включая другие загруженные обычные сцены; это может отклонить близкую расстановку даже при фактическом зазоре между частями здания.
- У готовых домов без GeneratedBuilding нет автоматического распознавания. Деревья, заборы, дорожное полотно, все проёмы и игровые маршруты не проверяются. Это не NavMesh/Physics/FPS-приёмка.
- Полные bounds видимой геометрии и поддерживаемых коллайдеров проверяются после сборки во временной сцене. Если лестница или свес выходит за участок, публикация отменяется без переноса дома в целевую сцену.
- Предпросмотр профиля использует штатный генератор, который может создать новые производные mesh assets в существующем content-addressed кэше. Это не полностью безфайловая операция. Исходные prefab/profile/меши не перезаписываются.
- Г1 не делает облегчённые дома, streaming, меблировку, генерацию добычи, NPC или интеграцию world-save. CityGeneratedLot/ApartmentSlot/buildingId — авторские метки, не SaveIdentity.

## Передача второму разработчику и ИИ

Исходники: Assets/WorldAuthoring. Данные — CityBuildingCatalog, CityBlockPlan, CityLot; связь результата — CityGeneratedLot. Редактор — CityBlockBuilder и WorldAuthoringWindow (UI Toolkit). Validate должен оставаться read-only: без Physics, Undo, сохранения, авторинга ассетов и изменения сцен. Генерация сначала строит один выбранный лот в Preview Scene, проверяет полную геометрию, затем переносит только успешный новый корень и регистрирует Undo.

Не добавлять destructive Rebuild/overwrite/delete существующих домов без отдельного задания. У своего уже размещённого лота допускается только строгое соответствие единственному маркеру и buildingId; чужие/повторные ID отклоняются. Prefab с GeneratedBuilding требует путь через профиль, иначе скопируются внутренние авторские ID. Prefab с CityGeneratedLot, SaveIdentity, WorldSaveObject, WorldItem, Trader, EnemyBrain или Missing Script отклоняется.

Не создавать второй генератор домов/дорог. Дальнейшие этапы: Г2 — облегчённые представления и стоимость одного дома; Г3 — новые измеренные типы секций/квартир; Г4 — дворы/наполнение с seed и защищёнными ручными группами; затем игровые точки добычи/населения по существующим контрактам. Не считать эти этапы уже реализованными.

## Проверки

CityBlockChecks.Run(false) создаёт собственную временную аддитивную сцену и временные assets, проверяет валидатор, Preview/cleanup, размещение/дубли/ручные дочерние объекты, сериализацию плана и сохранность прежних сцен/файлов. Run(true) дополнительно строит один этаж/один подъезд настоящего V5 в Preview. Undo/Redo пропускается вне Recovery, чтобы не запустить посторонние обработчики глобального Undo на пользовательской сцене. Результаты фактического прогона дописываются ниже.

## Исправление видимости результата проверки

Результат теперь закреплён под выбором плана, вне прокрутки параметров. Он сохраняется при перестроении формы и перекомпиляции окна. Пустая область картинки скрыта; успешный Preview показывает изображение и прокручивает к нему. Рядом с этажами указаны ограничения V4/V5: 1–9 этажей, 1–8 подъездов. Невалидный ввод (например 12 этажей) возвращается до сканирования существующих зданий города. Значения пользователя автоматически не исправляются и не сохраняются. Сцену и план пользователя для этой правки не перестраивать.

Проверка исправления: нативные команды CheckPlan и ShowPreview на отдельном in-memory плане с 12 этажами вернули явное сообщение «этажи 1–9»; Label находится вне прокрутки параметров, Preview не создавался. Пользовательский план восстановлен без изменения значений. Компиляция без ошибок. Полная матрица геометрии повторно не запускалась — изменены только вывод результата и ранний отказ невалидного ввода.
