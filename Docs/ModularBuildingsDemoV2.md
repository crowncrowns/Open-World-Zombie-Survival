## Изменения генератора

- Межсекционные PartyWall удалены. Полы доходят до общих границ секций без прежних0,4м разрывов. Внутри остаются только оболочки лестничных клеток/подъездных площадок и квартирные дверные проёмы. Пространство вне них общее, пригодно для ручного размещения квартир с заходом в соседнюю секцию.
- Передняя площадка углублена до Z=4,5м, марши сдвинуты на3м назад. Центры маршей(-0,75;0,75;5,85)/(+0,75;2,25;5,85), второй yaw180. Промежуточная площадка Z=7,2…8,7/Y=1,5; отверстия перекрытий сохранены. Все координаты фиксированы шаблоном, лестницы не размещаются случайно.
- На каждом этаже три двери: L/R при Z=0 и L2 при Z=3. У каждой есть рама, полотно, фурнитура, петля, устойчивый ApartmentSlot и ManualContent. Все60петель и полотен исходно localRotation=identity; наружные4двери тоже закрыты. ID имеют вид `demo-v2-001/E01/F01/L`, `/R`, `/L2`; +Z слота направлен из подъезда в будущее квартирное пространство. Открывать вручную следует Door_Hinge.
- В каждом подъезде полноценная входная дверь. Рама/полотно основаны на Door_Single_Metal, вертикальные ручки по13см с креплениями с обеих сторон имеют отдельный металлический материал. Проход проверен при временном открывании на95°; сохранённое состояние закрытое.
- В библиотеке три производных материала и три prefab варианта: WoodSlats, RedTufted, DarkUpholstery. Использованы существующие BaseColor/Normal/AO/MetallicSmoothness/Height карты из соответствующих `ApartmentDoor_*_01`. Геометрия и положение квартирных ручек скопированы из соответствующих дверей Building_Shk_68_FINISH — того же исходного здания, на которое ссылается SampleScene. Исходные материалы, prefab и сцены не переписаны. Отдельный производный UprightDoorCube исправляет перевёрнутую вертикальную UV-развёртку, чтобы глазки/накладки/ручки совпадали.
- На стекло назначен существующий `DirtyHazyGlass_01/M_Glass_DirtyHazy.mat`; папки с точным именем DirtyHazyGlass_0 нет, найден соответствующий набор `_01`. Размеры окон/рамы не растягиваются. Сохранены коллайдеры закрытого стекла, добавляемые только на экземпляры.
- Вместо плит с поперечными швами сделана единая замкнутая кровельная геометрия с уклоном2% к двум краям: подъём коньковой линии всего0,124м на6,2м, не высокая скатная крыша. Материал именно `RustyWindowSill_01/M_Roof_01_URP`. Отдельная потолочная плита перекрывает верх здания, не создавая межсекционных щелей. В библиотеке рассчитаны кровли для1–8подъездов.
- На каждый подъезд приходится одна полая кирпичная вентиляционная шахта с металлическим козырьком/опорами и один воздуховод. Они привязаны к двум фиксированным боковым зонам будущих квартир, вне лестничной шахты. Воздуховод повторно использует Vent&Pipe; козырёк — геометрию Prism(7) существующего здания. ProBuilder-топология козырька восстановлена **на временной копии** и сохранена самостоятельным mesh asset. Цоколи имеют нижнюю грань по уклону кровли и горизонтальную верхнюю площадку; пропсы стоят на них, не утоплены в крышу. Полные инженерные каналы внутри будущих квартир не проектировались.

## Повторная генерация и защита

Меню **Tools/Zombie Survival/Модульные дома MVP**: выбрать демо-профиль V2, задать год/этажи/подъезды и постоянный ID; Preview, Generate, Validate, Save Prefab. Шаблон поддерживает1–9этажей/1–8подъездов, год — только метаданные. Generate работает через Undo и не сохраняет сцену автоматически. Preview — временная отдельная preview-scene; для ручного наполнения используйте сценовый дом или сохранённый prefab.

Действующий дом не перестраивается и не удаляется: занятый buildingId вызывает отказ до создания объектов, Save Prefab выбирает новый путь. Для сравнения новой версии используйте другой ID и отдельную тестовую сцену. Автоматического переноса ручных квартир между версиями нет. Ручные изменения защищены от генератора, но не от ручного Delete/замены prefab пользователем. ID ApartmentSlot не являются SaveIdentity: WorldSave-регистрация/автоматическое игровое открывание дверей в этот этап не добавлялись.

Повторяемый контроль: **Tools/Zombie Survival/Дома MVP — создать тест и проверить**. Он создаёт новую отдельную тестовую сцену и prefab с уникальными именами, не перезаписывая Review. Не загружайте два образца с одинаковыми ID вместе как игровой мир. Промежуточные версии первого этапа и ранние V2-образцы убраны из Assets в `work/ModularDemoV2/IntermediateAssets` вместе с .meta, с сохранением возможности отката.
