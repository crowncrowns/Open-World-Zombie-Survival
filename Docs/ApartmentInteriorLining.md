# Внутренняя облицовка окон квартир

## Использование

Облицовка закрывает внутренние поверхности ordinary/balcony/triple фасадных проёмов материалом конкретной комнаты. Наружные материалы, настоящие рамы, створки и двери не меняются.

Новые V6 дома вызывают `BuildingInteriorLining` из `BuildingApartments.Add`. Для существующего дома или после авторской смены отделки боковых стен выбрать корень и выполнить **Tools → Zombie Survival → Город — обновить внутреннюю отделку выбранного дома**. Команда поддерживает Undo и оставляет сцену dirty; нужную сцену записывают отдельно после проверки. Повторное применение заменяет только управляемую облицовку и не накапливает копии. Исходную квартиру, профили и материалы не переписывать.

## Геометрия и материалы

Готовые формы:

- `Assets/Maps/Buildings/Walls/Prefabs/Inside/Wall_Window_Base.prefab`;
- `Assets/Maps/Buildings/Walls/Prefabs/Inside/Wall_BalconyExit_Interactive.prefab`;
- `Assets/Maps/Buildings/Walls/Prefabs/Inside/Wall_Window_Triple_Interactive.prefab`.

Авторская позиция корня template игнорируется: его геометрия измеряется относительно собственного корня и совмещается с фактическим внешним модулем. Проём не масштабируется. Треугольники стен с UV/нормалями обрезаются по интервалу комнаты вдоль фасада и высоте этажа; нормали преобразуются inverse-transpose. Геометрические расчёты используют стабильные относительные матрицы и не зависят от большого world offset.

Даже частичный край соседнего модуля получает обрезанную облицовку, если пересечение более5мм. Доборы заполняют только остаток после объединения покрытия всех соседних модулей, поэтому не перекрывают соседние окна. Внутренняя поверхность добора согласована с фактической толщиной template.

Комнатные интервалы выводятся из актуальных перпендикулярных полноэтажных стен на глубине0.2–1м от фасада. Материал берётся с обращённой к комнате грани боковой стены текущего экземпляра. Парные стены с разными материалами по сторонам обслуживают разные комнаты. Если обе соседние границы задают конфликтующие материалы или стену нельзя определить, план возвращает diagnostic/error до применения, без подмены глобальным материалом профиля.

Для21 source-квартиры используются occupiedRegions и реальная геометрия экземпляра. Для двух legacy-процедурных квартир без source/regions этаж берётся по родительскому ApartmentSlot, область — по подтверждённым buildingLocalBounds. Старые floor/room metadata не исправляются и не копируются в новый источник.

## Владение и API

Editor API `BuildingInteriorLining`: `Plan(b).ToJson()`, `Preflight(b)`, `Apply(b, recordUndo)`, `Apply(plan, recordUndo)`, `Validate(b)`. Планирование не изменяет сцену. Производные immutable mesh assets — `Assets/ModularBuildings/Generated/InteriorLiningMeshes`; исходники и importer Read/Write не меняются. Non-readable source mesh читается через Editor MeshData API.

`GeneratedInteriorLining` находится непосредственно под GeneratedApartment, **вне авторского prefab-instance**. Управляемый объект содержит marker, Transform, MeshFilter и MeshRenderer, без новых коллайдеров, рам, интерактивных створок и дверей. `ValidateNoGeneratedWalls` допускает только адресную проверенную облицовку с нужным владельцем/template/cache provenance. Это не разрешение на произвольные стены, generated envelope, тамбуры или коридоры; прежний запрет остаётся.

Проверки: актуальный room material, все вершины в room interval, проёмы всех копланарных модулей, непрерывность покрытия над проёмами и на краях интервалов. Они не заменяют визуальный просмотр, Main Play или NavMesh-проверку.

## Текущий контракт: точный стык без пересечения объёмов

По уточнению пользователя облицовка должна стоять **встык**, без воздушного промежутка и без утопления/пересечения объёмов. Задняя, обращённая к наружной стене грань облицовки — `lining MAXZ` — совпадает с внутренней гранью наружной стены `exterior MINZ` в координатах фасадного модуля. Формула размещения: `plane = externalMinZ − templateMaxZ`, **без дополнительного отступа и без1мм перекрытия**. Видимая лицевая грань естественно отстоит внутрь комнаты на толщину шаблона0.04/0.1м.

TemplateDepthBounds возвращает min/max по mesh bounds со стабильными относительными матрицами; сохраняет поддержку non-readable geometry и ненулевого root position. Validate сравнивает фактический MAXZ производного меша с MINZ стены, отдельно контролируя air и penetration с допуском0.05мм. Доборы остаются на фактической видимой внутренней поверхности, проёмы XY/room clipping/материалы не меняются.

Авторский ручной пример имел MAXZ около−.199694м при wall MINZ−.200000м (около0.3мм ручной точности); формула воспроизводит именно точный стык, а не это небольшое пересечение. Повторное применение обновит все153 управляемые облицовки, включая вручную подвинутый пример; source assets и старые квартирные metadata не переписываются.
