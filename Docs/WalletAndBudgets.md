# Т3: рублёвый кошелёк и бюджет

Wallet хранит целые рубли в long, старт по умолчанию 0. Деньги не ItemStack, не занимают вес/слоты. TryCredit/TryDebit/CanCredit/CanDebit принимают только положительные суммы; 0 и отрицательные отклоняются без событий. Credit/Debit — throwing-обёртки, Try API безопасно возвращает false. Переполнение и нехватка средств — полный отказ. Бесплатное действие будущего сервиса не вызывает Wallet с нулевой суммой.

TryTransferTo проверяет получателя, self-transfer, активность, обе суммы до записи; оба конечных баланса изменяются до Changed. Повторный вызов — отдельная явная команда, ledger/dedup не добавлены. Changed только при фактическом успешном изменении конечного баланса.

TraderBudget использует тот же Wallet, не второй баланс. Infinite — явный тестовый источник/приёмник: платежи исходят без списания резерва, входящие средства не увеличивают резерв. При конечный → infinite → конечный возвращается та же сохранённая конечная сумма. SetInfinite не применяет initial balance заново; режим не привязан к будущему профилю торговца. Перевод infinite → finite всё равно проверяет переполнение получателя; infinite → infinite успешен без изменений/Changed.

Awake/OnEnable и UI только инициализируют один раз. Отдельный AfterSceneLoad hook начинает новую Play-сессию со startingBalance, включая выключенные Domain+Scene Reload; затем применяет стартовый режим бюджета в определённом порядке. Повторный enable, открытие окна и смена режима не начисляют старт заново. Игрового сохранения на диск нет.
