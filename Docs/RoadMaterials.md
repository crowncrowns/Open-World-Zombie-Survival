# Материалы отдельных дорог

В SampleScene_TerrainRoads полотно разделено на 21 участок и 13 перекрёстков. Дороги сгруппированы по семи значениям ширины.

В Hierarchy откройте `Vidnoe — Editable Block Road Network → Generated road network → Road surfaces — grouped by width → Ширина … м`. Выберите `Asphalt — …` и перетащите материал на объект либо назначьте его в Mesh Renderer → Materials. Назначение сохраняется при Rebuild.

Другой способ: на исходном участке TerrainConformingRoad задайте `Surface Material`. Пустое поле наследует общий Asphalt сети. Перекрёстки находятся в `Junction surfaces — separate materials`; их материал также можно задавать в Junctions → Surface Material на корне сети.

Положение, форму и ширину меняйте на исходных дорогах, после этого нажмите Rebuild. Сохраните сцену Ctrl+S. Изменения материала проверены после Rebuild и повторного открытия тестовой сцены.
