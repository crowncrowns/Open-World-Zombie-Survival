## Резервные копии и откат

Авторитетный манифест: `Verification/TerrainBroadSmoothing_20261026/Backup.json`.

- `LiveBefore.unity` — копия живой сцены до применения, около 808 МБ; сохраняет и предшествовавшие несохранённые пользовательские изменения.

- `Assets/TerrainEditing/Backups/Vidnoe_BeforeBroadSmoothing_20261026 2.asset` — нативная копия живого Terrain до изменения.

Пока статическая сессия существует в Editor, явный `TerrainReliefSmoothing.Restore()` возвращает ссылки Terrain/Collider, исходные позиции и меши, данные травы и перестраивает SurfaceMap по исходной высоте. Он оставляет сцену dirty для проверки, не сохраняет её автоматически. Derived assets остаются как свидетельство операции. Самостоятельные дороги, перестроенные через ветку без network, требуют отдельной проверки при откате.

**Перекомпиляция/domain reload или закрытие Editor уничтожает статическую сессию и её raw snapshots:** после этого Restore не является доступным полным откатом. Не менять C# и не вызывать Refresh во время незавершённой живой транзакции. При утрате сессии использовать внешнюю полную `LiveBefore.unity` и Terrain backup для ручного восстановления с предварительным сохранением текущих пользовательских изменений. Не подменять живую сцену старым дисковым вариантом без сравнения: в нём могут отсутствовать прежние пользовательские правки.
