# Напольные таблички и здоровье зомби

## Где находится результат

- Сцена: `Assets/CharacterTesting/CharacterTest.unity`.
- Общий префаб: `Assets/Characters/Enemies/ZombieMaleActor.prefab`.
- Runtime: `Assets/Scripts/Presentation/FloorInformationPlaque.cs`, `ActorHealthIndicator.cs`, `HollowHealthRing.cs`.
- Editor: `Assets/Editor/WorldSpacePresentationSetup.cs`.
- Шрифт: `Assets/Characters/Presentation/WorldText.asset` (динамический TMP, LiberationSans из TMP Essentials).
- Меню: **Tools → Character Lab → Apply Compact Plaques and Zombie Health Ring**.

Меню работает только вне Play Mode в уже открытой CharacterTest. Оно не открывает и не заменяет другую сцену, исключает объекты additive-сцен, сохраняет текущую сцену вместе с её имеющимися изменениями и общий префаб. Повторный запуск не создаёт вторые таблички или второй индикатор. Старую SampleScene этот инструмент не меняет.

## Таблички полигона

37 статических инструкций переведены на небольшие плоские таблички перед станциями. Полный исходный текст сохранён, включая строки управления и пояснения. Две динамические подписи оружейных мишеней не преобразованы: их по-прежнему обновляет `WeaponPracticeTarget`.

Старые компоненты TextMesh остаются источниками текста для существующих генераторов. `FloorInformationPlaque` отключает только их MeshRenderer и копирует строку в дочерний TMP. Не удалять эти TextMesh и не включать их старые Renderer: иначе нарушится совместимость старых setup-скриптов либо вернутся огромные надписи. Изменение текста старым генератором отражается на табличке автоматически.

Статические Sign-хелперы `ActorIntegrationSetup`, `InventoryAndCrawlSetup`, `PlayerHealthSetup`, `PlayerInteractionSetup` и заголовок `WeaponLabSetup` вызывают `ConfigurePlaque`. У мишеней остаётся прежний владелец подписи. При добавлении другого генератора статических инструкций также вызывать `WorldSpacePresentationSetup.ConfigurePlaque(text)` после заполнения TextMesh.

Размеры: короткая подпись **1,04 × 0,40 м**, многострочная **2,00 × 0,96 м**, высота над полом **0,035 м**. Это Canvas размером260×100 или500×240 при масштабе0,004. TMP автоматически подбирает размер14–24, не обрезает текст; фон тёмный, буквы светлые. У табличек нет Collider, Raycaster и влияния на препятствия.

Положение проверено относительно геометрии. Таблички ползания, потолка, падения и прыжка вынесены из-под крыш/платформ. Основные уточнённые позиции: roll Z53,5; head collision Z54,5; landing Z57; running jump X−8/Z51; crouch Z4,5; stealth cover X50/Z−18. Для правки положения перемещать дочерний `Floor plaque`, не препятствие. Размер меняется через его RectTransform/масштаб, цвет — через Image и TMP. Существующие таблички при повторном запуске меню не переставляются.

## Полое радиальное кольцо HP

На корне общего префаба один ActorHealthIndicator с существующим корневым Health. Дочерний Health indicator — мировой Canvas с небольшим **полым кольцом без цифр**. Объект TMP числа удалён, а не скрыт. Все экземпляры общего префаба получают новый вид.

Красная часть показывает оставшееся здоровье; белый сектор — потерю HP. Сектор начинается на 12 часах и растёт по часовой стрелке:100% HP — весь красный,75% —75% красного и25% белого,25% —25% красного и75% белого. Это прототип по описанию пользователя с ориентиром на круговой индикатор цели GTAIV, без заявления о точном воспроизведении оригинального UI.

Историческое имя класса/файла HollowHealthRing сохранено ради GUID и prefab-ссылок, но теперь Graphic рисует две кольцевые дуги парными inner/outer вершинами; центр прозрачный, без вершин и полигонов. Внутренний радиус по умолчанию 0,68 внешнего (Inner Radius Ratio в Inspector). ActorHealthIndicator передаёт Health.Normalized; SetVerticesDirty вызывается только при изменении доли HP. Числового TMP UI в индикаторе больше нет.

Диаметр **0,24 м**: RectTransform128×128, масштаб родителя0,001875. Центр следует за костью головы плюс **0,28 м** вверх и опускается вместе с моделью при ползании. Для будущей модели можно явно указать Head; без него используется корень+1,65 м. Необязательное поле View Camera назначает камеру, иначе используется Camera.main с тегом MainCamera.

Размер меняется масштабом Health indicator. Красный цвет — Color компонента HollowHealthRing, белый — Lost Health Color. Дочерний объект называется Radial health ring. Graphic требует CanvasRenderer; наследуемый Graphic.OnValidate обновляет геометрию при настройке Inspector.

ConfigureZombie теперь модернизирует существующий индикатор: повторно использует Canvas/Graphic, удаляет старый объект числа, обновляет размер, положение и связь Health.Normalized. Повторный запуск не оставляет старое кольцо и не создаёт дубликат. Общий пункт меню остаётся **Tools → Character Lab → Apply Compact Plaques and Zombie Health Ring** для совместимости с прежней инструкцией. Метод ConfigureZombie можно вызвать отдельно, без обработки табличек.

Индикатор только читает Health: не создаёт IDamageable/CombatTarget, не наносит урон, не издаёт GameplayNoise/звук, не добавляет Camera, AudioListener, EventSystem, Raycaster или Collider. Canvas скрывается при смерти/отключении Health и возвращается после Revive; OnDisable индикатора тоже его выключает. Опрос в LateUpdate сохраняет обновление при отключённых Domain Reload и Scene Reload. Мировой Canvas проходит обычную проверку глубины: стена естественно закрывает индикатор, собственной LOS-логики нет.
