# Moscow Trees — исправленный пакет FBX для Unity

Целевой проект: Open-World-Zombie-Survival, Unity **6000.6.3f1**, URP **17.6.0**.

В комплекте 32 дерева (8 пород × 4 варианта), по 3 LOD: всего 96 настоящих бинарных FBX, экспортированных Blender 4.5.14 LTS. В `Assets/MoscowTrees/Prefabs` лежат готовые префабы с LODGroup, CapsuleCollider на стволе и MoscowTreeWind. Исходные GLB сохранены без изменений в `Sources/Moscow_Summer_Trees_Unity_Full.zip`.

## Импорт

1. Выйдите из Play Mode. Если старый MoscowTrees уже импортирован, сохраните его копию **за пределами Assets**, затем уберите старую папку `Assets/MoscowTrees`. Две копии C#-скриптов внутри Assets вызовут ошибки дублирования классов. Объекты старых префабов в сценах потребуется заменить: у прежнего архива не было стабильного комплекта `.meta`.
2. Скопируйте папку `Assets/MoscowTrees` из этого архива в `Assets` проекта. Копируйте вместе с `.meta`, чтобы сохранить ссылки материалов, моделей и префабов. Папки Tools, Sources и Verification в Assets не нужны.
3. Дождитесь импорта и компиляции. Используйте готовые префабы из `Assets/MoscowTrees/Prefabs`. При необходимости пересоберите их через **Tools → Moscow Trees → Build All 32 FBX Wind Prefabs**. Генератор обновляет материалы под активный render pipeline.
4. Перетащите префаб в сцену, включите Play. Настройте MoscowTreeWind в Inspector.

LOD: пороги относительной высоты экрана 0.55 / 0.20 / 0.035, затем отсечение. LOD2 исходного набора — упрощённые пересекающиеся плоскости с листвой. Коллайдер — приближённая капсула нижней части ствола, не коллайдер кроны. Настраивайте радиус и высоту под игровой масштаб.

## Ветер

Это **процедурная анимация C# в Unity**, вращающая сохранённые узлы `Wind_Trunk` и `Wind_Branch_*`. **Запечённых AnimationClip внутри FBX нет**, Animator не требуется. Ветер не связан с Unity WindZone.

Настройки сериализуются в префабе/сцене:

- Enable Wind — включение; выключение возвращает исходную позу.
- Wind From — откуда дует ветер; North = мировой +Z, East = +X. Например, West перемещает крону в сторону +X. Custom Travel Direction — вектор **куда** движется воздух, в мировых XZ.
- Wind Strength — безразмерный множитель амплитуды. Wind Speed — частота колебаний, не физические м/с.
- Gustiness и Gust Frequency — выраженность и частота порывов.
- Trunk/Branch Bend Degrees — амплитуды поворота в градусах.
- Variation Seed — фаза колебаний; Animate In Edit Mode — предпросмотр вне Play.

Все LOD одного дерева используют одинаковые фазы по имени ветки. Это повороты отдельных частей, а не непрерывная деформация ствола. На большом лесу стоимость тысяч Transform и Renderer нужно профилировать в вашей сцене. Набор не является решением для массовой GPU-анимации растительности или готовым Terrain Tree/SpeedTree-ассетом.

## Проверка и ограничения

Подробности, результаты Unity и контрольные суммы: `Verification/REPORT_RU.md`, `Verification/blender_validation.json`, `Verification/unity_validation.txt` и `SHA256SUMS.txt`.

Все 96 моделей проверены через GLB → импорт Blender → экспорт FBX → повторный импорт Blender. Сравниваются число мешей, вершин, треугольников, наличие UV, имена узлов ветра и мировые границы. Unity-проверка дополнительно проверяет три LOD, размеры и вертикальную ось, ссылки на текстуры, коллайдеры, URP-материалы и движение/сброс ветра у 32 префабов. Это изолированный тест с версией Unity и настройками рендеринга целевого проекта; игровые сцены, производительность леса и сборка полной игры не проверялись. HDRP не проверялся.

## Повторная конвертация из подтверждённых исходников

Распакуйте `Sources/Moscow_Summer_Trees_Unity_Full.zip`. Запустите Blender из PowerShell (укажите свои абсолютные пути):

```powershell
& 'E:\UnityTools\Blender\blender.exe' --background --python-exit-code 1 --python 'C:\TreePack\Tools\ConvertAndVerify.py' -- 'C:\TreePack\Sources\Moscow_Summer_Trees_Unity' 'C:\TreePack\Rebuilt\Assets\MoscowTrees'
```

Первый аргумент после `--` — каталог, содержащий `Models/LOD0`, `Models/LOD1`, `Models/LOD2`; второй — выходной MoscowTrees. Скрипт экспортирует 96 FBX и завершится с ошибкой при несовпадении повторно импортированной геометрии. Отчёт появится в `Rebuilt/blender_validation.json`. Для полного Unity-пакета добавьте папки Textures, Scripts, Editor и Shaders из исправленного комплекта, затем запустите генератор префабов в Unity.

Модели и текстуры исходного комплекта разрешены его автором к использованию и изменению в игровых проектах: см. `Assets/MoscowTrees/LICENSE_AND_NOTES.txt`.
